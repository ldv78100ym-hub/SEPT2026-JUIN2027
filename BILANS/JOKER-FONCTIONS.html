1 Taux de variation d'une fonction

Pour une fonction \(f\) définie sur un intervalle contenant \(a\) et \(b\) (avec \(a \neq b\)), le taux de variation entre \(a\) et \(b\) est :

\[ \tau\left(a,b\right) = \dfrac{f\left(b\right) - f\left(a\right)}{b - a} \]

Ce nombre correspond au coefficient directeur de la droite sécante à la courbe \(C_f\) passant par les points de coordonnées \(\left(a\,; f\left(a\right)\right)\) et \(\left(b\,; f\left(b\right)\right)\).

Lien avec la dérivation : quand \(b \to a\), le taux de variation tend vers \(f'\left(a\right)\), le nombre dérivé.

Interprétation du signe

FonctionTaux de variationCourbe
Constante \(\dfrac{f\left(b\right)-f\left(a\right)}{b-a} = 0\) Droite horizontale
Croissante \(\dfrac{f\left(b\right)-f\left(a\right)}{b-a} \geq 0\) Courbe qui monte
Décroissante \(\dfrac{f\left(b\right)-f\left(a\right)}{b-a} \leq 0\) Courbe qui descend

2 Polynômes de degré 2

Une fonction polynôme de degré 2 s'écrit :

\[ f\left(x\right) = ax^2 + bx + c \quad \left(a \neq 0\right) \]

Sa forme factorisée, lorsqu'elle existe, est :

\[ f\left(x\right) = a\left(x - x_1\right)\left(x - x_2\right) \]

où \(x_1\) et \(x_2\) sont les racines réelles.

Racines, sommet et axe de symétrie

  • Le nombre de racines réelles est 0, 1 ou 2.
  • Le sommet \(S\) a pour coordonnées \(\left(-\dfrac{b}{2a}\,; f\!\left(-\dfrac{b}{2a}\right)\right)\).
  • La parabole possède un axe de symétrie d'équation \(x = -\dfrac{b}{2a}\).

Signe et allure selon \(a\)

À retenir : pour le degré 2, utiliser la forme factorisée \(a\left(x-x_1\right)\left(x-x_2\right)\) quand les racines sont connues.

3 Polynômes de degré 3

Une fonction polynôme de degré 3 s'écrit :

\[ f\left(x\right) = ax^3 + bx^2 + cx + d \quad \left(a \neq 0\right) \]

Sa forme factorisée, lorsqu'elle existe, est :

\[ f\left(x\right) = a\left(x - x_1\right)\left(x - x_2\right)\left(x - x_3\right) \]

où \(x_1, x_2, x_3\) sont les racines réelles.

Nombre de racines et comportement à l'infini

  • Le nombre de racines réelles est 1 ou 3.
  • Le signe et les limites dépendent du signe de \(a\).
Signe de \(a\)Limite en \(+\infty\)Limite en \(-\infty\)
\(a > 0\)\(f\left(x\right) \to +\infty\)\(f\left(x\right) \to -\infty\)
\(a < 0\)\(f\left(x\right) \to -\infty\)\(f\left(x\right) \to +\infty\)
À retenir : pour le degré 3, factoriser quand une racine est évidente. Pas de discriminant \(\Delta\) en première technologique.

4 Équations \(x^2 = c\) et \(x^3 = c\)

Équation \(x^2 = c\) avec \(c \geq 0\)

\[ x = \sqrt{c} \quad \text{ou} \quad x = -\sqrt{c} \]

Deux solutions si \(c > 0\), une seule \(\left(x=0\right)\) si \(c=0\).

Équation \(x^3 = c\) avec \(c \in \mathbb{R}\)

\[ x = \sqrt[3]{c} = c^{1/3} \]

Une unique solution réelle pour tout réel \(c\).

Racine cubique

\(\sqrt[3]{a}\) est l'unique réel tel que \(\left(\sqrt[3]{a}\right)^3 = a\).

\[ \sqrt[3]{a^3} = a \quad \text{et} \quad \left(\sqrt[3]{a}\right)^3 = a \]

5 Algorithmique – Balayage

Principe : pour résoudre \(f\left(x\right) = k\) sur \(\left[a\,; b\right]\) où \(f\) est monotone, on parcourt l'intervalle avec un pas donné jusqu'à dépasser \(k\).

Algorithme Python

def balayage(f, a, b, k, pas):
    x = a
    while x <= b and f(x) < k:
        x = x + pas
    return x if x <= b else None

Avec condition if/else

def balayage_secure(f, a, b, k, pas):
    if f(a) > k:
        return "k trop petit"
    x = a
    while x <= b and f(x) < k:
        x = x + pas
    return x if x <= b else "k trop grand"

Tableau de signes de \(f\left(x\right) = x^2 - 4\)

\(f\left(x\right) = \left(x-2\right)\left(x+2\right)\). Racines : \(x = -2\) et \(x = 2\). Le zéro de \(f\) est marqué par une ligne verticale en pointillés avec le chiffre \(0\) au centre.

Tableau de variations de \(f\left(x\right) = x^2 - 4\)

Sommet au point \(S\left(0\,; -4\right)\) — minimum global.

Tableau de signes de \(f\left(x\right) = x^3 - x\)

\(f\left(x\right) = x\left(x-1\right)\left(x+1\right)\). Racines : \(x = -1\), \(x = 0\), \(x = 1\). Le zéro de \(f\) est marqué par une ligne verticale en pointillés avec le chiffre \(0\) au centre.

Tableau de variations de \(f\left(x\right) = x^3 - x\)

Dérivée \(f'\left(x\right) = 3x^2 - 1\). Maximum local en \(x = -\dfrac{1}{\sqrt{3}}\), minimum local en \(x = \dfrac{1}{\sqrt{3}}\).
