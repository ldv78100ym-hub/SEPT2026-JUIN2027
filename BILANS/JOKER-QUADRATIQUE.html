Second degré

1 Définition et forme développée

Une fonction polynôme du second degré est une fonction \(f\) définie sur \(\mathbb{R}\) par :

\[ f(x) = ax^2 + bx + c \]

où \(a\), \(b\), \(c\) sont des nombres réels et \(a \neq 0\).

Cette écriture est appelée forme développée. Elle est utile pour les calculs directs (évaluation, dérivation, somme de fonctions).

2 Rôle des coefficients \(a\), \(b\), \(c\)

Coefficient \(a\) : orientation et ouverture

  • \(a > 0\) : les branches de la parabole sont orientées vers le haut.
  • \(a < 0\) : les branches sont orientées vers le bas.
  • \(|a| > 1\) : les branches sont resserrées (la parabole est plus « étroite »).
  • \(|a| < 1\) : les branches sont écartées (la parabole est plus « large »).

Coefficient \(b\) : coefficient directeur de la tangente en \(x = 0\)

La tangente à la parabole au point d’abscisse \(0\) a pour équation \(y = bx + c\). Son coefficient directeur est \(b\). Autrement dit, \(f'(0) = b\).

Coefficient \(c\) : ordonnée à l’origine

Le point d’intersection de la parabole avec l’axe des ordonnées est \((0, c)\). On a \(f(0) = c\).

3 Forme canonique et sommet

Toute fonction polynôme du second degré peut s’écrire sous la forme canonique :

\[ f(x) = a(x - \alpha)^2 + \beta \]

où :

\[ \alpha = -\dfrac{b}{2a}, \qquad \beta = f(\alpha) \]

Le point \(S(\alpha, \beta)\) est le sommet de la parabole. C’est le point où la fonction atteint son extremum :

  • Si \(a > 0\), \(\beta\) est le minimum de \(f\) sur \(\mathbb{R}\).
  • Si \(a < 0\), \(\beta\) est le maximum de \(f\) sur \(\mathbb{R}\).

4 Variations

Le sens de variation de \(f\) se lit sur la forme canonique :

  • Si \(a > 0\) : \(f\) est décroissante sur \(]-\infty, \alpha]\), puis croissante sur \([\alpha, +\infty[\).
  • Si \(a < 0\) : \(f\) est croissante sur \(]-\infty, \alpha]\), puis décroissante sur \([\alpha, +\infty[\).

5 Forme factorisée et racines

Lorsque le trinôme possède deux racines réelles \(x_1\) et \(x_2\) (c’est-à-dire deux solutions de l’équation \(f(x) = 0\)), on peut écrire :

\[ f(x) = a(x - x_1)(x - x_2) \]

On a alors :

\[ f(x_1) = 0 \quad \text{et} \quad f(x_2) = 0 \]

L’abscisse du sommet est la moyenne des racines :

\[ \alpha = \dfrac{x_1 + x_2}{2} \]

6 Résolution de \(X^2 = k\)

La résolution de l’équation \(X^2 = k\) (où \(k\) est un réel) dépend du signe de \(k\) :

  • Si \(k < 0\) : aucune solution réelle (un carré est toujours positif ou nul).
  • Si \(k = 0\) : une seule solution, \(X = 0\).
  • Si \(k > 0\) : deux solutions, \(X = -\sqrt{k}\) et \(X = \sqrt{k}\).

7 Résolution de \(f(x) = k\)

Pour résoudre \(f(x) = k\), on peut adapter la méthode selon la valeur de \(k\) :

Cas \(k = 0\)

  • Avec la forme développée : se ramener à la forme canonique puis résoudre \((x - \alpha)^2 = -\beta / a\).
  • Avec la forme factorisée : utiliser l’équation produit \(a(x - x_1)(x - x_2) = 0\), d’où \(x = x_1\) ou \(x = x_2\).

Cas \(k = c\)

  • Avec la forme développée : factoriser \(f(x) - c\), puis résoudre.
  • Avec la forme factorisée : développer puis résoudre \(x(ax + b) = 0\).

Autres cas

Se ramener à la forme canonique puis résoudre \((x - \alpha)^2 = \dfrac{k - \beta}{a}\).

Exemple concret. Pour \(f(x) = 2x^2 - 4x + 1\) et \(k = 1\) (cas \(k = c\)) :
\(f(x) - 1 = 2x^2 - 4x = 2x(x - 2) = 0\), donc \(x = 0\) ou \(x = 2\).

8 Signe du trinôme

Le signe de \(f(x)\) dépend du signe de \(a\) et de l’existence de racines (ou du signe de \(\beta\)) :

  • Si \(a > 0\) et \(\beta > 0\) : \(f(x) > 0\) pour tout \(x\).
  • Si \(a > 0\) et \(\beta = 0\) : \(f(x) \geqslant 0\), avec \(f(x_0) = 0\).
  • Si \(a > 0\) et \(\beta < 0\) : \(f(x) > 0\) à l’extérieur des racines, \(f(x) < 0\) entre les racines.
  • Si \(a < 0\) et \(\beta < 0\) : \(f(x) < 0\) pour tout \(x\).
  • Si \(a < 0\) et \(\beta = 0\) : \(f(x) \leqslant 0\), avec \(f(x_0) = 0\).
  • Si \(a < 0\) et \(\beta > 0\) : \(f(x) < 0\) à l’extérieur des racines, \(f(x) > 0\) entre les racines.

Les tableaux de signes correspondants sont présentés dans le volet 3.

9 Synthèse des trois formes

Forme Expression Utilité principale
Développée \(ax^2 + bx + c\) Calculs directs, évaluation
Canonique \(a(x - \alpha)^2 + \beta\) Sommet, variations, extremum
Factorisée \(a(x - x_1)(x - x_2)\) Racines, signe
À retenir.
— La forme canonique donne directement le sommet \((\alpha, \beta)\).
— La forme factorisée donne les racines et permet le tableau de signes.
— Pour passer de la forme développée à la forme canonique, on détermine les coordonnées du sommet de la parabole.
— Pour résoudre \(f(x) = 0\), on cherche les racines évidentes ou on utilise la forme canonique.
