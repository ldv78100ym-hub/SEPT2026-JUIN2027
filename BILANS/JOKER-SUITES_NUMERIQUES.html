Suites numériques
Survolez les nœuds de la carte mentale et du graphe pour afficher les contenus détaillés.

1Définition et vocabulaire

Une suite numérique \(\left(u_n\right)\) est une application qui, à tout entier \(n\) d'une partie de \(\mathbb{N}\), associe un nombre réel \(u_n\).

  • Le nombre \(u_n\), aussi noté \(u(n)\), est le terme de rang \(n\).
  • \(u_0\) est le premier terme de la suite (appelé aussi terme initial).
  • On note \(\left(u_n\right)\) la suite tout entière et \(u_n\) le terme de rang \(n\) : ce sont deux objets différents.

Les deux formes de définition décrivent la même suite : la forme explicite donne \(u_n\) directement à partir de \(n\), la forme récurrente donne \(u_{n+1}\) à partir de \(u_n\).

2Forme explicite et forme récurrente

FormeÉcritureCe qu'il faut savoir
Explicite \(u_n = f(n)\) On calcule directement n'importe quel terme à partir de son rang \(n\). Aucun terme précédent n'est nécessaire.
Récurrente \(u_{n+1} = f\left(u_n\right)\) Chaque terme se calcule à partir du précédent. Il faut obligatoirement connaître le premier terme \(u_0\).

Exemple : \(u_n = n^2 - 3n\)

Cette suite est définie de façon explicite. On calcule les premiers termes en remplaçant \(n\) par sa valeur :

Rang \(n\)01234
Terme \(u_n\)\(0\)\(-2\)\(-2\)\(0\)\(4\)

Détail : \(u_0 = 0^2-3\times 0 = 0\) ; \(u_1 = 1^2-3\times 1 = -2\) ; \(u_2 = 2^2-3\times 2 = -2\) ; \(u_3 = 3^2-3\times 3 = 0\) ; \(u_4 = 4^2-3\times 4 = 4\).

La représentation graphique d'une suite est un nuage de points : l'abscisse est le rang \(n\), l'ordonnée est le terme \(u_n\).

3Sens de variation d'une suite

  • Croissante : pour tout \(n\), \(u_{n+1} \geq u_n\).
  • Décroissante : pour tout \(n\), \(u_{n+1} \leq u_n\).
  • Constante : pour tout \(n\), \(u_{n+1} = u_n\).

Méthode générale

On étudie le signe de la différence \(u_{n+1} - u_n\) :

  • si \(u_{n+1} - u_n \geq 0\) pour tout \(n\), la suite est croissante ;
  • si \(u_{n+1} - u_n \leq 0\) pour tout \(n\), la suite est décroissante ;
  • si \(u_{n+1} - u_n = 0\) pour tout \(n\), la suite est constante.

4Suites arithmétiques

Une suite \(\left(u_n\right)\) est arithmétique lorsqu'il existe un réel \(r\) (appelé raison) tel que, pour tout \(n\) :

\[ u_{n+1} = u_n + r \]

On passe d'un terme au suivant en ajoutant toujours le même nombre \(r\) : la variation absolue est constante.

Reconnaissance

Pour montrer qu'une suite est arithmétique, on calcule la différence \(u_{n+1} - u_n\) et on vérifie qu'elle est constante (indépendante de \(n\)). Cette constante est la raison \(r\).

Variation selon le signe de \(r\)

RaisonSens de variationInterprétation graphique
\(r > 0\)croissanteLes points montent régulièrement : ils sont alignés.
\(r < 0\)décroissanteLes points descendent régulièrement : ils sont alignés.
\(r = 0\)constanteLes points sont sur une droite horizontale.

Les points représentant une suite arithmétique sont alignés.

5Suites géométriques \(\left(u_n > 0\right)\)

Une suite \(\left(u_n\right)\) à termes strictement positifs est géométrique lorsqu'il existe un réel \(q > 0\) (appelé raison) tel que, pour tout \(n\) :

\[ u_{n+1} = q \times u_n \]

On passe d'un terme au suivant en multipliant toujours par le même nombre \(q\) : la variation relative est constante.

Reconnaissance

Pour montrer qu'une suite (à termes non nuls) est géométrique, on calcule le quotient \(\dfrac{u_{n+1}}{u_n}\) et on vérifie qu'il est constant (indépendant de \(n\)). Cette constante est la raison \(q\).

Variation selon la valeur de \(q\)

RaisonSens de variationInterprétation graphique
\(q > 1\)croissanteCroissance de plus en plus rapide (allure exponentielle).
\(0 < q < 1\)décroissanteDécroissance vers \(0\) (allure exponentielle décroissante).
\(q = 1\)constanteLes points sont sur une droite horizontale.

6Autres modèles : suites arithmético-géométriques

Lorsque \(u_{n+1} = a \times u_n + b\) avec \(a \neq 1\) et \(b \neq 0\), la suite n'est ni arithmétique ni géométrique : la différence \(u_{n+1} - u_n\) n'est pas constante et le rapport \(\dfrac{u_{n+1}}{u_n}\) non plus.

Type de croissanceOpération constanteFamille de suite
Croissance linéaireajout constantSuite arithmétique
Croissance exponentiellemultiplication constanteSuite géométrique
Autres modèles\(u_{n+1} = a\,u_n + b\), \(a \neq 1\), \(b \neq 0\)Ni arithmétique ni géométrique

Reconnaissance en pratique

  • Différence constante \(\;\Rightarrow\;\) suite arithmétique.
  • Rapport constant \(\;\Rightarrow\;\) suite géométrique.
  • Ni l'un ni l'autre \(\;\Rightarrow\;\) autre modèle.

Exemple : \(u_{n+1} = 0{,}5\,u_n + 2\) avec \(u_0 = 0\)

Ici \(a = 0{,}5 \neq 1\) et \(b = 2 \neq 0\). Les premiers termes sont \(0\) ; \(2\) ; \(3\) ; \(3{,}5\) ; \(3{,}75\) ; \(3{,}875\) ; … La suite est croissante et ses termes se rapprochent de \(4\).

7Algorithmique (sauf STD2A)

Les programmes ci-dessous calculent le terme de rang \(n\) d'une suite, puis recherchent un seuil.

Suite arithmétique — boucle for

def terme_arithmetique_for(u0, r, n):
    u = u0
    for i in range(n):
        u = u + r
    return u

Suite arithmétique — boucle while

def terme_arithmetique_while(u0, r, n):
    u = u0
    i = 0
    while i < n:
        u = u + r
        i = i + 1
    return u

Suite géométrique — boucle for

def terme_geometrique_for(u0, q, n):
    u = u0
    for i in range(n):
        u = u * q
    return u

Suite géométrique — boucle while

def terme_geometrique_while(u0, q, n):
    u = u0
    i = 0
    while i < n:
        u = u * q
        i = i + 1
    return u

Recherche de seuil avec condition if/else

def seuil_arithmetique(u0, r, S):
    # Trouve le plus petit n tel que u_n >= S
    u = u0
    n = 0
    if r <= 0 and u0 < S:
        return "Pas de seuil atteint"
    else:
        while u < S:
            u = u + r
            n = n + 1
        return n

La boucle for s'utilise quand le nombre d'itérations est connu à l'avance ; la boucle while s'utilise quand on s'arrête sur une condition (seuil, précision, etc.).

\(0 < q < 1\) : décroissante

Graphiquepoints alignéspoints sur une courbe exponentielle

À retenir

En première technologique, on utilise uniquement la relation de récurrence. L'expression explicite \(u_n = u_0 + n\,r\) et \(u_n = u_0 \times q^{\,n}\) est étudiée en terminale.

Trois situations à savoir lire

  • Suite géométrique alternée : raison négative \(\left(q < 0\right)\), les termes changent de signe à chaque étape.
  • Suite géométrique croissante : \(q > 1\) et \(u_0 > 0\), la croissance est exponentielle.
  • Suite arithmétique avec termes négatifs : \(u_0\) négatif et \(r > 0\), la suite devient positive à partir d'un certain rang.
