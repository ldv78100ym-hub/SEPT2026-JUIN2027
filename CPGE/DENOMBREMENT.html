📚 Cours de référence complet — Méthodes & Fondamentaux

🎯 Philosophie : vaincre l'abstraction par la méthode. Le dénombrement rebute car il paraît abstrait. En réalité, 90 % des exercices se résolvent en se posant quatre questions concrètes avant tout calcul :
  • 1. L'ordre compte-t-il ? (un podium ≠ un comité : 1er-2e-3e change le résultat, l'ordre de désignation d'un groupe ne change rien)
  • 2. Les éléments peuvent-ils se répéter ? (tirage avec ou sans remise, lettres d'un code avec ou sans doublon)
  • 3. Tout l'univers est-il utilisé ? (ranger n objets sur n places = permutation ; en choisir k parmi n = arrangement ou combinaison)
  • 4. L'énoncé contient-il « au moins un » ? → passez aussitôt par l'événement contraire (« aucun »), presque toujours plus simple.

1Principe multiplicatif : l'arbre des choix

Si une expérience enchaîne plusieurs étapes indépendantes, le nombre total de scénarios est le produit du nombre de choix de chaque étape :
Total = n1 × n2 × … × nk

Exemple concret : un mot de passe de 4 lettres, chaque lettre choisie parmi 26 sans restriction : 26 × 26 × 26 × 26 = 26⁴ = 456 976. On dessine un arbre : de la racine partent 26 branches, puis de chaque nœud 26 nouvelles branches, etc.

2Principe additif : additionner des cas disjoints

Si une situation se découpe en cas qui ne se chevauchent jamais (disjoints), on additionne les effectifs de chaque cas :
Total = card(Cas 1) + card(Cas 2) + …

Exemple : une personne choisit une LV1 parmi 3 langues vivantes et 2 anciennes. Choix possibles : 3 + 2 = 5.

⚠️ Piège majeur : si les cas se chevauchent, l'addition simple compte deux fois les éléments communs. C'est exactement ce que corrige la formule d'inclusion-exclusion (section 8) : card(A ∪ B) = card(A) + card(B) − card(A ∩ B).

3k-uplets : quand la répétition est libre (nk)

Un k-uplet d'un ensemble à n éléments est une suite ordonnée de k éléments, chacun choisi librement parmi les n (avec remise). Chaque position est indépendante :
n × n × … × n (k fois) = nk

Exemples : codes PIN à 4 chiffres → 10⁴ = 10 000 ; plaques « 2 lettres + 3 chiffres » → 26² × 10³ = 676 000.

⚠️ Si une position est imposée (le code commence par 9), cette position ne contribue que 1 choix, pas 10.

4Permutations : ranger complètement (n!)

Une permutation de n objets distincts est un rangement complet des n objets sur n places :
n! = n × (n − 1) × (n − 2) × … × 2 × 1

Exemple : anagrammes de MATHS (5 lettres distinctes) : 5! = 120.

Permutations avec répétitions (anagrammes) : si certaines lettres sont identiques, échanger entre elles des lettres jumelles ne crée pas de nouveau mot. On divise :

n! / (n1! × n2! × … × np!)

Exemple : RADAR (5 lettres : 3 R, 2 A) : 5! / (3! × 2!) = 120 / 12 = 10 anagrammes distinctes.

5Arrangements : choisir avec ordre, sans remise

Un arrangement de k éléments parmi n est une suite ordonnée de k éléments distincts pris parmi n :
Ank = n × (n − 1) × … × (n − k + 1) = n! / (n − k)!

Exemple : podium (or-argent-bronze) parmi 10 coureurs : A103 = 10 × 9 × 8 = 720. Le même trio dans un ordre différent donne un podium différent !

6Combinaisons : choisir sans ordre

Une combinaison de k éléments parmi n est un sous-groupe de k éléments : l'ordre de désignation n'a aucune importance :
nk = n!k! (n − k)!

Astuce visuelle : une poignée de k billes tirée les yeux fermés — peu importe l'ordre où elles tombent dans la main.

Propriété fondamentale (lien arrangement / combinaison) : chaque combinaison de k éléments engendre k! arrangements :

Ank = nk × k!    d'où    nk = Ankk!

Symétrie : nk = nn−k — choisir les k élus ou désigner les n−k exclus revient au même.

7Le triangle de Pascal : la machine à identités

Chaque coefficient est la somme des deux du dessus : nk = n−1k−1 + n−1k. Raison concrète : dans un groupe de n personnes contenant Léa, les comités de k personnes soit contiennent Léa (on complète avec k−1 parmi n−1), soit ne la contiennent pas (k parmi n−1).
n = 01
n = 111
n = 2121
n = 31331
n = 414641
n = 515101051
n = 61615201561

Identités à connaître : la somme d'une ligne vaut 2n (nombre de sous-ensembles) ; la somme des diagonales donne le « bâton de hockey » n0 + n+11 + … ; la colonne 2 redonne 1 + 2 + … + (n−1) = n2.

8Inclusion-exclusion & complémentaire

Deux ensembles — pour compter A ou B, on additionne puis on retire l'intersection comptée deux fois :

card(A ∪ B) = card(A) + card(B) − card(A ∩ B)

Trois ensembles — les zones doubles ont été comptées 2 fois, le centre 3 fois. On retire les paires, puis on remettre le centre :

card(A∪B∪C) = Σ card − Σ card(paires) + card(A∩B∩C)

Complémentaire (« au moins un ») — ne listez jamais les cas complexes, calculez le contraire :

card(« au moins un ») = Total − card(« aucun »)

Exemple : multiples de 2 ou 5 dans [1 ; 100] : 50 + 20 − 10 = 60 (les 10 multiples de 10 étaient comptés deux fois).

📖 Lexique & Définitions du Dénombrement

Cardinal : nombre d'éléments d'un ensemble fini. Noté card(E) ou |E|.
k-uplet : suite ordonnée de k éléments, choisis avec répétition possible. Il y en a nk dans un ensemble à n éléments.
Arrangement Ank : suite ordonnée de k éléments distincts pris parmi n. Ank = n!/(n−k)!.
Permutation : réarrangement complet de n éléments distincts. Il y en a n!.
Permutation avec répétition : rangement de n objets dont certains sont identiques : n!/(n1!×…×np!).
Anagramme : mot obtenu en permutant les lettres d'un mot. Si toutes les lettres sont distinctes : n! ; sinon, formule avec répétitions.
Coefficient binomial nk : nombre de sous-ensembles de k éléments d'un ensemble à n éléments (choix sans ordre, sans remise).
Triangle de Pascal : tableau triangulaire des nk, où chaque case est la somme des deux du dessus.
Intersection (A ∩ B) : ensemble des éléments communs à A et B.
Réunion (A ∪ B) : ensemble des éléments appartenant à A ou à B (au moins l'un des deux).
Ensembles disjoints : ensembles sans aucun élément commun : card(A ∪ B) = card(A) + card(B).
Complémentaire : éléments de l'univers qui n'appartiennent pas à l'ensemble considéré : card(Ā) = card(U) − card(A).
Inclusion-exclusion : card(A ∪ B) = card(A) + card(B) − card(A ∩ B) ; généralisable à 3 ensembles et plus.
Partition : découpage d'un ensemble en sous-ensembles non vides, deux à deux disjoints, dont la réunion est l'ensemble entier.
Bijection : correspondance un-à-un entre deux ensembles : ils ont le même cardinal. Outil roi du dénombrement indirect.
Double comptage : technique qui compte un même ensemble de deux manières différentes pour en déduire une formule.
Principe des tiroirs : si n+1 objets sont répartis dans n tiroirs, un tiroir contient au moins 2 objets.
Étoiles et barres : modèle pour répartir k objets identiques entre p destinataires : k+p−1p−1 façons.
Événement contraire : pour « au moins un », le contraire est « aucun ». Toujours compter le plus simple des deux.
Dérangement : permutation sans élément à sa place initiale. Exemple type : « aucune lettre dans la bonne enveloppe ».
