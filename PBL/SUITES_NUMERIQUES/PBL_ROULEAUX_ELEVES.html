🧠 Activité préparatoire – Découverte d’une astuce de calcul

Calculez rapidement la somme \(1 + 2 + 3 + \dots + 10\).
Pour cela, écrivez cette somme normalement sur une ligne, puis écrivez-la à l’envers (de 10 à 1) juste en dessous. Additionnez ces deux lignes colonne par colonne.

1 Exploration – Testez la régularité Essai/Erreur

Un rouleau est un empilement de tours parfaits. Le premier tour a pour rayon $r$, le second $r+e$, le troisième $r+2e$, etc.

1.a) Calculez les longueurs des 3 premiers tours : $u_1$, $u_2$, $u_3$ (laissez $\pi$ si nécessaire).

1.b) Testez si $u_2 - u_1 = u_3 - u_2$. Si c’est le cas, quelle est la raison ?

1.c) En déduire une relation de récurrence $u_{k+1} = u_k + \dots$

📝 Réponse pour la Phase 1 (1.a, 1.b, 1.c)

Commandes LaTeX utiles pour cette phase
\pi
Exemple d'écriture : x = \pi
Rendu visuel : \(x = \pi\)
Affiche la constante π. S'utilise dans les expressions mathématiques.
\rho
Exemple d'écriture : \rho = \dfrac{m}{V}
Rendu visuel : \(\rho = \dfrac{m}{V}\)
Lettre grecque souvent utilisée pour désigner une grandeur physique.
_{...}
Exemple d'écriture : a_1, a_{n+1}
Rendu visuel : \(a_1\), \(a_{n+1}\)
Permet d'écrire des indices. Pour un indice composé, placer entre accolades.
+ , - , = , ( )
Exemple d'écriture : (x - y) = (z + w)
Rendu visuel : \((x - y) = (z + w)\)
Symboles de base pour les opérations, comparaisons et regroupements.
\cdots
Exemple d'écriture : 1, 4, 9, \cdots
Rendu visuel : \(1, 4, 9, \cdots\)
Points de suspension centrés, utilisés pour indiquer une suite logique.

2 Généralisation & Somme

2.a) Donnez l’expression de $u_k$ en fonction de $k$, $r$ et $e$.

2.b) Pour $n$ tours, la longueur totale est $L_n = u_1 + u_2 + \dots + u_n$.

🔴 Défi : Additionner 100 termes à la main est impossible. Vous devez découvrir une formule pour cette somme.

2.c) 🔍 Relisez le document pour exprimer la somme $S_n$. Montrez que :

$$ S_n = n \times \dfrac{u_1 + u_n}{2} $$

2.d) Appliquez cette formule pour obtenir $L_n$ en fonction de $n$, $r$, $e$.

📝 Réponse pour la Phase 2 (2.a, 2.c, 2.d)

Commandes LaTeX utiles pour cette phase
\dfrac{num}{den}
Exemple d'écriture : \dfrac{a + b}{c}
Rendu visuel : \(\dfrac{a + b}{c}\)
Crée une fraction en style d'affichage.
\times
Exemple d'écriture : n \times (a + b)
Rendu visuel : \(n \times (a + b)\)
Affiche le symbole de multiplication ×.
\dots
Exemple d'écriture : a_1 + a_2 + \dots + a_n
Rendu visuel : \(a_1 + a_2 + \dots + a_n\)
Points de suspension bas, utilisés pour une suite dans une somme.
\cdots
Exemple d'écriture : 1 + 3 + \cdots + n
Rendu visuel : \(1 + 3 + \cdots + n\)
Points de suspension centrés.
\sum et \displaystyle
Exemple d'écriture : \displaystyle\sum_{i=1}^{n} a_i
Rendu visuel : \(\displaystyle\sum_{i=1}^{n} a_i\)
Symbole de somme. Les limites s'écrivent avec _ et ^.
\bigl( ... \bigr)
Exemple d'écriture : \bigl(x + y\bigr)
Rendu visuel : \(\bigl(x + y\bigr)\)
Parenthèses de taille adaptée.
