Rappel important : rang et indice

Dans ce document, on distingue les deux notions suivantes :

  • l'indice d'un terme est le nombre \(n\) tel que ce terme s'écrive \(u_n\) ;
  • le rang d'un terme est sa position dans la liste ordonnée des termes, en commençant à 1.

Ainsi, si la suite commence à \(u_0\), on a :

\[ \text{rang }1=u_0,\qquad \text{rang }2=u_1,\qquad \ldots,\qquad \text{rang }r=u_{r-1}. \]

Si la suite commence à \(u_1\), alors \(\text{rang }r=u_r\).

Exemple. Pour la suite \(u_0=5,\ u_1=7,\ u_2=9,\ldots\), le terme de rang \(3\) est \(u_2=9\), tandis que le terme d'indice \(3\) est \(u_3=11\).

Mots-clés : suite définie par récurrence · première rencontre · découverte guidée de la variation

Soit \((u_n)\) la suite définie par :

Découverte Cette suite est définie par récurrence :
  • on connaît le premier terme \(u_0\) ;
  • on connaît une relation qui permet de calculer chaque terme à partir du précédent : \(u_{n+1} = \dfrac{1}{2}u_n + 1\).
Concrètement, pour calculer \(u_1\), on remplace \(u_n\) par \(u_0\) dans la relation. Pour calculer \(u_2\), on remplace \(u_n\) par \(u_1\). Et ainsi de suite, de proche en proche.
  1. Comment est définie la suite ?
  2. Déterminer le terme de rang 3.
  3. Déterminer le terme d'indice 3.
  4. Calculer \(u_0,u_1,u_2,u_3,u_4\), puis conjecturer la variation de la suite.
  5. Pour comprendre pas à pas le comportement de la suite, suivre les étapes ci-dessous. Aucun outil technique n'est nécessaire : il suffit d'observer les nombres.
    1. Calculer les différences \(u_1-u_0\), \(u_2-u_1\), \(u_3-u_2\), \(u_4-u_3\), \(u_5-u_4\).
    2. Quel est le signe de chacune de ces différences ? Sont-elles toutes du même signe ?
    3. Que peut-on en déduire sur la comparaison de chaque terme avec le terme qui le précède ?
    4. Quel est alors le sens de variation de la suite ?
    5. Vers quelle valeur les termes \(u_n\) semblent-ils se rapprocher ? Vérifier cette intuition : remplacer \(u_n\) par cette valeur dans la relation \(u_{n+1} = \dfrac{1}{2}u_n + 1\) et observer si le résultat est égal à cette même valeur.

Suites numériques — généralités · rang & indice · modes de définition · variation
Règle
  • L'indice : le nombre \(n\) tel que le terme s'écrive \(u_n\).
  • Le rang : la position dans la liste, en partant de 1.
  • suite commençant à \(u_0\) : \(\text{rang } r = u_{r-1}\) ;
  • suite commençant à \(u_p\) : \(\text{rang } r = u_{p+r-1}\) ;
  • suite commençant à \(u_1\) : \(\text{rang } r = u_r\).

Liste exhaustive \(u_0,\ldots,u_5\) : elle est finie.

Attention Aucun terme d'indice > 5 n'existe.

Selon l'expression de \(u_n\), la méthode d'étude varie :

  • polynôme : calculer \(u_{n+1}-u_n\) ;
  • rationnelle : réduire au même dénominateur ;
  • racine carrée : quantité conjuguée ;
  • composée : combiner les techniques.

Point \(A_n(n\,;u_n)\) : abscisse = indice, ordonnée = terme.

Le terme de rang 4 correspond au point d'abscisse \(3\) (suite à partir de \(u_0\)).

Précision Les valeurs lues graphiquement sont données aux erreurs de lecture près. On admettra une marge d'incertitude d'environ un quart de graduation.
Règle 1 Somme algébrique de deux fractions : on réduit au même dénominateur : \[ \frac{a}{b} + \frac{c}{d} = \frac{a\times d + c\times b}{b\times d}. \]
Règle 2 Somme d'une fraction et d'un entier : \[ k + \frac{a}{b} = \frac{k\times b + a}{b}. \]
Règle 3 Produit d'un entier par une fraction : \[ k \times \frac{a}{b} = \frac{k\times a}{b}. \]
Règle 4 Produit de deux fractions : \[ \frac{a}{b}\times\frac{c}{d} = \frac{a\times c}{b\times d}. \]
Règle 5 Fraction irréductible : on divise numérateur et dénominateur par leur pgcd : \[ \frac{a}{b} = \frac{a \div g}{b \div g}, \quad g = \mathrm{pgcd}(a,b). \]
Outil 1 Différence \(u_{n+1}-u_n\) (universel).
Outil 2 Quotient \(u_{n+1}/u_n\) (si tous les termes sont strictement positifs).
Outil 3 Fonction associée (si \(u_n=f(n)\)).

Pour étudier le signe de \(\sqrt{A} - \sqrt{B}\) (avec \(A,B \geq 0\)), on multiplie et divise par la quantité conjuguée \(\sqrt{A} + \sqrt{B}\) :

\[ \sqrt{A} - \sqrt{B} = \frac{(\sqrt{A} - \sqrt{B})(\sqrt{A} + \sqrt{B})}{\sqrt{A} + \sqrt{B}} = \frac{A - B}{\sqrt{A} + \sqrt{B}}. \]
Identité remarquable On utilise \((X-Y)(X+Y) = X^2 - Y^2\).

Le dénominateur est strictement positif. Le signe de la différence est donc celui de \(A - B\).

Découverte

Une suite est définie par récurrence lorsqu'on connaît :

  • son premier terme (ex. \(u_0 = 5\)) ;
  • une relation entre deux termes consécutifs (ex. \(u_{n+1} = \dfrac{1}{2}u_n + 1\)).

Pour calculer les termes, on avance pas à pas :

  • on part de \(u_0\) ;
  • on calcule \(u_1\) à partir de \(u_0\) ;
  • on calcule \(u_2\) à partir de \(u_1\) ;
  • et ainsi de suite.
Astuce Pour observer la variation, on calcule les différences \(u_{n+1} - u_n\) : si elles sont toutes du même signe, la suite est monotone.
