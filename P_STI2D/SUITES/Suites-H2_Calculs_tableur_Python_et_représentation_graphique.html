📚 Rappels : Tableur, Python et nuage de points

Pour générer les termes d’une suite et interpréter son nuage de points, on utilise des outils numériques. La forme du nuage permet de conjecturer la nature de la suite.

📊 Tableur

=2*A2+3
Formule en B2 si A2 contient $n$. Recopier vers le bas pour générer la liste.
💡 Astuce : Utilisez la poignée de recopie pour étendre la formule.

🐍 Python – Liste en compréhension

[2*n+3 for n in range(5)]
Génère les 5 premiers termes : $n=0,1,2,3,4$.
💡 Astuce : `range(5)` va de 0 à 4.

🐍 Python – Boucle

L.append(2*n+3)
Ajoute successivement les termes dans une liste.
💡 Astuce : Pensez à initialiser `L = []` avant la boucle.

📈 Nuage de points

$(n, u_n)$
En abscisse le rang $n$, en ordonnée la valeur $u_n$.
💡 Astuce : Les points alignés indiquent une suite arithmétique.

📈 Suite arithmétique

Points alignés
Si les points sont alignés, la suite est arithmétique ($u_n = a n + b$).
💡 Astuce : La différence $u_{n+1} - u_n$ est constante.

📈 Suite géométrique

Croissance exponentielle
Si la croissance est exponentielle (points sur une courbe $a^n$), la suite est géométrique.
💡 Astuce : Le rapport $u_{n+1} / u_n$ est constant.
