📚 Rappels : Fonctions de référence

Voici les principales familles de fonctions utilisées pour définir une suite de manière explicite ($u_n = f(n)$). Reconnaître la forme générale permet d'identifier le type d'évolution et de prévoir l'allure du nuage de points.

📈 Affine

$u_n = a n + b$
Graphique : droite. Pente : $a$. Si $a > 0$ : croissante ; $a < 0$ : décroissante.

📊 Quadratique

$u_n = a n^2 + b$
Graphique : parabole. Si $a > 0$ : minimum ; $a < 0$ : maximum.

📉 Cubique

$u_n = a n^3 + b$
Graphique : courbe en "S". $a > 0$ : croissante ; $a < 0$ : décroissante.

√ Racine carrée

$u_n = \sqrt{a n + b}$
Domaine : $a n + b \geq 0$. Croissante si $a > 0$.

⅟ Inverse

$u_n = \dfrac{a}{n + b}$
Graphique : hyperbole. Décroissante si $a > 0$.

| | Valeur absolue

$u_n = |a n + b|$
Graphique : forme en "V". Décroissante puis croissante.

📈 Exponentielle

$u_n = k \times a^n$
Si $a > 1$ : croissance rapide ; si $0 < a < 1$ : décroissance.

🔄 Trigonométrique

$\sin(n)$ ou $\cos(n)$
Périodiques, oscillent entre $-1$ et $1$. Ex : $\sin\left(\dfrac{n\pi}{2}\right)$ donne $0, 1, 0, -1, \dots$
