1 Le repère orthonormé \((O, I, J)\)

La « scène de théâtre » de toute la trigonométrie : un repère \((O, I, J)\) du plan est dit orthonormé lorsque le triangle \(OIJ\) est rectangle isocèle en \(O\).

« Ortho » : angle droit

Les droites \((OI)\) et \((OJ)\) sont perpendiculaires : elles forment un angle de \(90^\circ\) en \(O\).

« Normé » : norme égale à 1

Les segments \([OI]\) et \([OJ]\) ont la même longueur : \(OI = OJ = 1\). Les vecteurs \(\vec{\imath}\) et \(\vec{\jmath}\) sont des vecteurs unitaires (de longueur 1).

À retenir : dans un repère orthonormé \((O, \vec{\imath}, \vec{\jmath})\), l'axe \((O, \vec{\imath})\) est l'axe des abscisses et l'axe \((O, \vec{\jmath})\) est l'axe des ordonnées. Tout point \(M\) y est repéré par ses coordonnées \((x\,;y)\).

2 Transformations du plan (rappels)

2.1 Symétrie axiale (orthogonale)

Notation : \(S_d(A)\) se lit « symétrique du point \(A\) par rapport à la droite \(d\) » ou « image du point \(A\) par la symétrie d'axe \(d\) ».

Équivalence caractéristique :

$$B = S_d(A) \iff d \text{ est la médiatrice du segment } [AB]$$

Autrement dit : la droite \(d\) est perpendiculaire à \([AB]\) et passe par son milieu ; \(d\) joue le rôle de « miroir ».

2.2 Symétrie centrale de centre \(O\) (\(S_O\))

Le point \(O\) est le milieu du segment \([AA']\) : le point \(A'\) est « à l'opposé » de \(A\), de l'autre côté de \(O\), à la même distance. C'est aussi une rotation de centre \(O\) et d'angle \(180^\circ\).

2.3 Rotations de \(\pm 90^\circ\)

  • Rotation d'angle \(+90^\circ\) : déplacement de \(90^\circ\) dans le sens anti-horaire, appelé sens direct ou sens trigonométrique.
  • Rotation d'angle \(-90^\circ\) : déplacement de \(90^\circ\) dans le sens horaire, appelé sens indirect.
Application : la symétrie d'axe \((Oy)\) envoie \(A(x\,;y)\) sur \(A'(-x\,;y)\) : l'abscisse est opposée (\(x_{A'} = -x_A\)) et l'ordonnée est inchangée (\(y_{A'} = y_A\)).

3 Symétries du repère : effet sur coordonnées et angles

Soit \(M(x\,;y)\), \(M \neq O\), dans un repère orthonormé \((O, \vec{\imath}, \vec{\jmath})\). On note \(\theta = (\vec{\imath}, \overrightarrow{OM})\) son angle orienté. Les trois symétries associées au repère agissent ainsi (angles modulo \(360^\circ\)) :

SymétrieAxe / centreCoordonnées de l'imageAngle image
\(S_{(O,\vec{\imath})}\)axe des abscisses\((x, y) \mapsto (x, -y)\)\(\theta \mapsto -\theta\)
\(S_{(O,\vec{\jmath})}\)axe des ordonnées\((x, y) \mapsto (-x, y)\)\(\theta \mapsto 180^\circ - \theta\)
\(S_{O}\)origine \(O\)\((x, y) \mapsto (-x, -y)\)\(\theta \mapsto \theta + 180^\circ\)

Moyen mnémotechnique :

  • Symétrie d'axe \((O, \vec{\imath})\) : l'ordonnée \(y\) change de signe.
  • Symétrie d'axe \((O, \vec{\jmath})\) : l'abscisse \(x\) change de signe.
  • Symétrie centrale : les deux coordonnées changent de signe.

Exemples corrigés (type exercices)

\(A(5\,;-2)\) : on a \(A_1 = S_{(O,\vec{\imath})}(A) = (5\,;2)\), \(A_2 = S_{(O,\vec{\jmath})}(A) = (-5\,;-2)\), \(A_3 = S_O(A) = (-5\,;2)\).

Avec \(A\left(\dfrac{3}{2}\,;-\dfrac{5}{4}\right)\) : \(A_1 = \left(\dfrac{3}{2}\,;\dfrac{5}{4}\right)\), \(A_2 = \left(-\dfrac{3}{2}\,;-\dfrac{5}{4}\right)\), \(A_3 = \left(-\dfrac{3}{2}\,;\dfrac{5}{4}\right)\). Avec \(A(\sqrt{5}\,;-\sqrt{2})\) : \(A_1 = (\sqrt{5}\,;\sqrt{2})\), \(A_2 = (-\sqrt{5}\,;-\sqrt{2})\), etc.

Identifier la transformation

Pour passer de \(A\) à \(A'\), on compare les coordonnées :

  • \(x' = x\) et \(y' = -y\) → symétrie d'axe \((O, \vec{\imath})\) ;
  • \(x' = -x\) et \(y' = y\) → symétrie d'axe \((O, \vec{\jmath})\) ;
  • \(x' = -x\) et \(y' = -y\) → symétrie de centre \(O\).

4 Angles orientés

Pour un point \(M \neq O\), on note \(\left(\vec{\imath}, \overrightarrow{OM}\right)\) l'angle orienté entre le vecteur \(\vec{\imath}\) (axe des abscisses) et le vecteur \(\overrightarrow{OM}\).

  • L'angle est orienté : positif dans le sens direct (anti-horaire), négatif dans le sens indirect (horaire).
  • Il est défini modulo \(360^\circ\) : \(35^\circ\), \(395^\circ\) et \(-325^\circ\) désignent la même position.

Effet des symétries sur l'angle orienté

Si \((\vec{\imath}, \overrightarrow{OA}) = \theta\), alors les images de \(A\) vérifient :

  • \((\vec{\imath}, \overrightarrow{OA_1}) = -\theta\) pour \(A_1 = S_{(O,\vec{\imath})}(A)\) ;
  • \((\vec{\imath}, \overrightarrow{OA_2}) = 180^\circ - \theta\) pour \(A_2 = S_{(O,\vec{\jmath})}(A)\) ;
  • \((\vec{\imath}, \overrightarrow{OA_3}) = \theta + 180^\circ\) pour \(A_3 = S_{O}(A)\).
À retenir : symétrie d'axe \((O,\vec{\imath})\) : \(\theta \mapsto -\theta\) ; symétrie d'axe \((O,\vec{\jmath})\) : \(\theta \mapsto 180^\circ - \theta\) ; symétrie centrale : \(\theta \mapsto \theta + 180^\circ\). Toujours modulo \(360^\circ\).

5 Conversion degré ↔ radian

Le radian est l'unité naturelle des angles : sur un cercle de rayon 1, un angle de 1 radian intercepte un arc de longueur 1. La correspondance fondamentale est :

$$180^\circ = \pi \text{ radians}$$ $$\text{radians} = \text{degrés} \times \dfrac{\pi}{180}, \qquad \text{degrés} = \text{radians} \times \dfrac{180}{\pi}.$$

6 Que signifie « modulo \(2\pi\) » ?

6.1 Le problème du « tour de trop »

Sur le cercle trigonométrique, plusieurs nombres peuvent repérer le même point \(M\) : il suffit d'ajouter ou de retirer un ou plusieurs tours complets.

6.2 Un même point, une infinité de nombres

$$\theta, \quad \theta + 2\pi, \quad \theta - 2\pi, \quad \theta + 4\pi, \quad \dots \quad \text{c'est-à-dire } \theta + 2k\pi, \; k \in \mathbb{Z}.$$

6.3 La notation « mod \(2\pi\) »

$$\theta \equiv \theta' \pmod{2\pi} \iff \exists k \in \mathbb{Z} : \theta = \theta' + 2k\pi.$$

Exemples : \(\dfrac{\pi}{6} \equiv \dfrac{13\pi}{6}\) ; \(\dfrac{\pi}{3} \equiv -\dfrac{5\pi}{3}\) ; \(\pi \equiv 3\pi \equiv -5\pi\).

6.4 Comparaison avec les degrés

$$\theta \equiv \theta' \pmod{360^\circ} \iff \theta = \theta' + 360k.$$

6.5 Pourquoi c'est indispensable

  • On choisit la mesure principale dans \(]-\pi\,;\pi]\).
  • Deux nombres congrus modulo \(2\pi\) donnent le même cosinus et le même sinus.
Conséquence : si \(\theta \equiv \theta' \pmod{2\pi}\), alors \(\cos\theta = \cos\theta'\) et \(\sin\theta = \sin\theta'\).

7 Mesure principale d'un angle

La mesure principale d'un angle orienté est l'unique mesure \(\alpha\) telle que

$$-\pi < \alpha \leq \pi \quad \text{ou} \quad -180^\circ < \alpha \leq 180^\circ.$$

Toute autre mesure s'écrit \(\alpha + 2k\pi\), \(k \in \mathbb{Z}\).

Méthode : ajouter ou retrancher autant de fois \(360^\circ\) (ou \(2\pi\)) que nécessaire.

8 Rotations d'angle \(\pm 90^\circ\)

Soit \(M(x\,;y)\), \(M'\) son image par la rotation de centre \(O\) :

Rotation \(+90^\circ\) (sens direct) : \(\quad M'(x'\,;y') = (-y\,;x)\).

Rotation \(-90^\circ\) (sens indirect) : \(\quad M'(x'\,;y') = (y\,;-x)\).

$$\text{Rotation } +90^\circ : \theta' = \theta + \dfrac{\pi}{2} \pmod{2\pi}$$ $$\text{Rotation } -90^\circ : \theta' = \theta - \dfrac{\pi}{2} \pmod{2\pi}$$

9 Le cercle trigonométrique

Le cercle trigonométrique est le cercle de centre \(O\) et de rayon 1, orienté dans le sens direct :

$$x^2 + y^2 = 1$$

À tout réel \(\theta\) correspond un unique point \(M\) tel que \((\vec{\imath}, \overrightarrow{OM}) \equiv \theta \pmod{2\pi}\).

10 Coordonnées d'un point du cercle : \((\cos\theta, \sin\theta)\)

Soit \(M\) un point du cercle trigonométrique et \(\Theta\) la mesure principale de \((\vec{\imath}, \overrightarrow{OM})\). Alors :

$$M = (\cos\Theta, \sin\Theta).$$

Le cosinus se lit sur l'axe des abscisses, le sinus sur l'axe des ordonnées.

$$\cos^2\Theta + \sin^2\Theta = 1$$
À retenir : \(-1 \leq \cos\theta \leq 1\), \(-1 \leq \sin\theta \leq 1\), et \(\cos\theta = \cos\theta'\) dès que \(\theta \equiv \theta' \pmod{2\pi}\).

11 Angles associés

11.1 Liaison avec les symétries

$$\cos(-\theta) = \cos\theta, \qquad \sin(-\theta) = -\sin\theta$$ $$\cos(\pi - \theta) = -\cos\theta, \qquad \sin(\pi - \theta) = \sin\theta$$ $$\cos(\pi + \theta) = -\cos\theta, \qquad \sin(\pi + \theta) = -\sin\theta$$

11.2 Liaison avec les rotations

$$\cos\left(\theta + \dfrac{\pi}{2}\right) = -\sin\theta, \qquad \sin\left(\theta + \dfrac{\pi}{2}\right) = \cos\theta$$ $$\cos\left(\theta - \dfrac{\pi}{2}\right) = \sin\theta, \qquad \sin\left(\theta - \dfrac{\pi}{2}\right) = -\cos\theta$$

11.3 Autres angles associés

$$\cos\left(\dfrac{\pi}{2} - \theta\right) = \sin\theta, \qquad \sin\left(\dfrac{\pi}{2} - \theta\right) = \cos\theta$$ $$\cos(2\pi - \theta) = \cos\theta, \qquad \sin(2\pi - \theta) = -\sin\theta$$

13 Compositions, réciproques et points invariants

13.1 Chaque symétrie est sa propre réciproque

$$S^{-1} = S, \qquad S_{(O,\vec{\imath})}^2 = S_{(O,\vec{\jmath})}^2 = S_O^2 = \mathrm{Id}.$$

13.2 Composer deux symétries

$$S_{(O,\vec{\jmath})} \circ S_{(O,\vec{\imath})} = S_{(O,\vec{\imath})} \circ S_{(O,\vec{\jmath})} = S_O$$

Règle : composée de deux symétries distinctes = la troisième.

13.3 Les trois symétries d'affilée

En enchaînant les trois symétries (dans n'importe quel ordre), on obtient l'identité.

13.4 Points invariants

  • \(S_{(O,\vec{\imath})}\) : axe des abscisses \((x\,;0)\).
  • \(S_{(O,\vec{\jmath})}\) : axe des ordonnées \((0\,;y)\).
  • \(S_O\) : uniquement \(O(0\,;0)\).

⭐ Synthèse : ce qu'il faut retenir

  • \(S_{(O,\vec{\imath})}\) : \(y \mapsto -y\), \(\theta \mapsto -\theta\).
  • \(S_{(O,\vec{\jmath})}\) : \(x \mapsto -x\), \(\theta \mapsto \pi - \theta\).
  • \(S_O\) : \((x,y) \mapsto (-x,-y)\), \(\theta \mapsto \theta + \pi\).

  • \(180^\circ = \pi\) ; tour complet \(= 360^\circ = 2\pi\) ; modulo \(2\pi\).
  • Mesure principale dans \(]-\pi\,;\pi]\).
