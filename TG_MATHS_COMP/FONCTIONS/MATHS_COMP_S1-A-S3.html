1. Limites et Asymptotes S1

1.1 Limites à l'infini

Définition : Soit $f$ définie sur $]a,+\infty[$. La limite de $f$ en $+\infty$ est $L$ si $f(x)$ peut être rendu aussi proche de $L$ que voulu pour $x$ assez grand. On note $\lim\limits_{x\to+\infty}f(x)=L$.

Limites de référence :

  • $\lim\limits_{x\to+\infty}x^n=+\infty$ ($n\ge1$) ; $\lim\limits_{x\to+\infty}\dfrac1{x^n}=0$
  • $\lim\limits_{x\to+\infty}e^x=+\infty$ ; $\lim\limits_{x\to+\infty}\ln x=+\infty$ ; $\lim\limits_{x\to-\infty}e^x=0$

1.2 Formes indéterminées

F.I. : $\infty-\infty$, $0\times\infty$, $\dfrac{\infty}{\infty}$, $\dfrac{0}{0}$.

Méthode : factoriser par le terme de plus haut degré en $\pm\infty$ ; factoriser par le terme problématique ou conjuguer en $0$.

1.3 Asymptotes

  • Horizontale : $\lim\limits_{x\to\pm\infty}f(x)=L$ ⇒ droite $y=L$.
  • Verticale : $\lim\limits_{x\to a}f(x)=\pm\infty$ ⇒ droite $x=a$.

2. Continuité et TVI S2

2.1 Continuité

Définition : $f$ est continue en $a$ si $\lim\limits_{x\to a}f(x)=f(a)$ ; sur un intervalle si continue en tout point. Intuitivement, on trace sans lever le crayon. Polynômes, rationnelles, $\exp$, $\ln$ et leurs composées sont continues sur leur domaine.

2.2 Le TVI

TVI (admis) : si $f$ est continue sur $[a,b]$, pour tout $k$ entre $f(a)$ et $f(b)$, il existe $c\in[a,b]$ tel que $f(c)=k$.
Corollaire (bijection) : si $f$ est continue et strictement monotone sur $[a,b]$, pour tout $k$ entre $f(a)$ et $f(b)$, l'équation $f(x)=k$ admet une unique solution dans $[a,b]$.
Méthode : 1) continuité, 2) signes de $f(a)$ et $f(b)$ opposés, 3) monotonie via $f'$, 4) conclure.

3. Dérivabilité S3

3.1 Nombre dérivé et tangente

Définition : $f$ dérivable en $a$ si $\dfrac{f(a+h)-f(a)}h$ admet une limite finie quand $h\to0$, notée $f'(a)$. Tangente : $y=f'(a)(x-a)+f(a)$.

3.2 Dérivées de composées

  • $(u+v)'=u'+v'$ ; $(uv)'=u'v+uv'$ ; $\left(\dfrac uv\right)'=\dfrac{u'v-uv'}{v^2}$
  • $(u\circ v)'=v'\times u'(v)$ ; $(e^u)'=u'e^u$ ; $(\ln u)'=\dfrac{u'}u$ ($u>0$)

4. Logarithme et Exponentielle S3

$\ln$ est la réciproque de $\exp$ sur $\mathbb{R}$.
Logarithme ($a,b>0$) : $\ln(ab)=\ln a+\ln b$ ; $\ln(a/b)=\ln a-\ln b$ ; $\ln(a^n)=n\ln a$ ; $\ln1=0$ ; $\ln e=1$ ; $\ln(1/a)=-\ln a$.
Exponentielle : $e^{x+y}=e^xe^y$ ; $e^{x-y}=e^x/e^y$ ; $e^{-x}=1/e^x$ ; $(e^x)^n=e^{nx}$ ; $e^0=1$.
Réciprocité : $\ln(e^x)=x$ ; $e^{\ln x}=x$ ($x>0$).

4.2 Limites et croissances comparées

  • $\lim\limits_{x\to0^+}\ln x=-\infty$ ; $\lim\limits_{x\to+\infty}\dfrac{\ln x}x=0$ ; $\lim\limits_{x\to+\infty}\dfrac{e^x}x=+\infty$
  • $\lim\limits_{x\to0}\dfrac{\ln(1+x)}x=1$ ; $\lim\limits_{x\to0}\dfrac{e^x-1}x=1$
