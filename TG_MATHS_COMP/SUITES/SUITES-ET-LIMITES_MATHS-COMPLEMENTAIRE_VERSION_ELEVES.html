Évaluation — Suites et limites

Terminale générale · option Mathématiques complémentaires · Durée : 100 minutes

⚠️ Mode test actif : le délai d'attente entre deux essais est actuellement suspendu. Pour le réactiver, passez DELAI_ESSAIS_ACTIF à true dans le script (voir le commentaire en tête de section).
Consignes
  • Vous disposez de 100 minutes non stop (tiers-temps +1/3 si PAP).
  • Le chronomètre démarre dès le clic sur « Commencer ». À la fin, la page se ferme automatiquement.
  • Une idée = une ligne. La 1re ligne est libre. Toute ligne suivante doit commencer par mais, ou, et, donc, or, ni, car ou par Finalement.
  • Mathématiques : tapez vos formules en LaTeX directement, sans taper les $ (l'application les ajoute automatiquement). Exemple : u_n = \dfrac{1}{n}.
  • Validation : Ctrl+Entrée (⌘+Entrée), clic sur ✓, ou perte de focus. L'aperçu LaTeX s'affiche alors sous la zone de saisie.
  • Édition : les boutons ✎ (modifier), ▲▼ (déplacer) et ✕ (supprimer) permettent de retravailler n'importe quelle ligne.
  • La réponse à une question est la ligne commençant par Finalement : elle sera encadrée.
  • Toute sortie de page, interruption ou longue inactivité est enregistrée automatiquement.
  • Le fichier final est un .json chiffré contenant toute la copie.
  • Vous pouvez refaire le devoir, mais il faut au moins 100 minutes entre deux débuts de devoir.
