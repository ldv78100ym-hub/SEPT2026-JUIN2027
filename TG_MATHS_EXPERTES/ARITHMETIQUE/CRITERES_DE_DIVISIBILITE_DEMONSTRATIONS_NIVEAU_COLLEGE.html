Divisibilité

Démonstrations générales

Choisir un diviseur
9 règles · 9 démonstrations générales
Aucun prérequis en arithmétique.

🧰 Boîte à outils — à lire avant de commencer

  • Multiple de $d$ : un nombre est un multiple de $d$ s'il apparaît dans la table de $d$. Par exemple, $12 = 3 \times 4$, donc $12$ est un multiple de $3$.
  • Chiffre des unités : c'est le chiffre le plus à droite. Dans $4\,738$, le chiffre des unités est $8$.
  • Propriété clé n°1 : si deux nombres diffèrent d'un multiple de $d$, alors soit les deux sont des multiples de $d$, soit aucun des deux ne l'est.
  • Propriété clé n°2 (nombres premiers) : si $d$ est un nombre premier et si $d$ divise un produit $a \times b$, alors $d$ divise $a$ ou $d$ divise $b$.
2

Divisibilité par 2

On regarde seulement le chiffre des unités.

Règle

Un nombre est divisible par $2$ si et seulement si son chiffre des unités est $0$, $2$, $4$, $6$ ou $8$.

Illustration

Exemples

  • ✓ $4\,738$ : le chiffre des unités est $8$, qui est pair. Donc $4\,738$ est dans la table de $2$ (en effet $4\,738 = 2 \times 2\,369$).
  • ✗ $4\,735$ : le chiffre des unités est $5$, qui est impair. Donc $4\,735$ n'est pas dans la table de $2$.
  • ✓ $1\,234\,560$ : le chiffre des unités est $0$, donc c'est un multiple de $2$.

Démonstration générale

Soit $N$ un entier naturel quelconque.

Étape 1 — On découpe le nombre

On note $b$ le chiffre des unités de $N$, et $a$ le nombre formé par tous les autres chiffres. Par définition de l'écriture décimale :

\[ N = 10a + b \qquad \text{avec } b \in \{0,1,2,\dots,9\}. \]

Étape 2 — La différence $N - b$ est un multiple de $2$

Calculons :

\[ N - b = (10a + b) - b = 10a = 2 \times 5a. \]

Donc $N - b$ est un multiple de $2$, quel que soit $a$.

Étape 3 — On applique la propriété clé n°1

Les nombres $N$ et $b$ diffèrent d'un multiple de $2$, donc :

$N$ est un multiple de $2$ $\iff$ $b$ est un multiple de $2$.

Étape 4 — On conclut

$b$ est un chiffre entre $0$ et $9$. Les seuls chiffres multiples de $2$ sont :

\[ 0,\; 2,\; 4,\; 6,\; 8. \]

\[ N \text{ est divisible par } 2 \iff b \in \{0,2,4,6,8\}. \]

La règle est donc démontrée pour tout entier $N$.

Vérification sur un exemple (facultatif). Pour $N = 4\,738$ : $b = 8$, qui est dans $\{0,2,4,6,8\}$, donc $4\,738$ est bien un multiple de $2$.
3

Divisibilité par 3

On additionne tous les chiffres.

Règle

Un nombre est divisible par $3$ si et seulement si la somme de ses chiffres est divisible par $3$.

Illustration

Exemples

  • ✓ $5\,412$ : $5+4+1+2 = 12$, et $12 = 3 \times 4$. Donc $5\,412$ est dans la table de $3$.
  • ✗ $4\,738$ : $4+7+3+8 = 22$, et $22$ n'est pas dans la table de $3$.
  • ✓ $7\,302$ : $7+3+0+2 = 12$, donc $7\,302$ est un multiple de $3$.

Démonstration générale

Soit $N$ un entier naturel quelconque, dont l'écriture décimale possède $n+1$ chiffres :

\[ N = d_n \times 10^n + d_{n-1} \times 10^{n-1} + \cdots + d_1 \times 10 + d_0, \]

où chaque $d_k$ est un chiffre entre $0$ et $9$. On note $S = d_n + d_{n-1} + \cdots + d_1 + d_0$ la somme des chiffres de $N$.

Étape 1 — Un lemme sur les puissances de 10

Lemme. Pour tout entier $k \geqslant 0$, il existe un entier $m_k \geqslant 0$ tel que :

\[ 10^k = 3\,m_k + 1. \]

Preuve du lemme (par récurrence).

  • Cas de base ($k=0$) : $10^0 = 1 = 3 \times 0 + 1$. Donc $m_0 = 0$ convient.
  • Hérédité : supposons que $10^k = 3\,m_k + 1$. Alors : \[ 10^{k+1} = 10 \times (3\,m_k + 1) = 30\,m_k + 10 = 3(10\,m_k + 3) + 1. \] Posons $m_{k+1} = 10\,m_k + 3 \geqslant 0$. Alors $10^{k+1} = 3\,m_{k+1} + 1$.
  • Conclusion : la propriété est vraie pour tout $k \geqslant 0$. ∎

Étape 2 — On remplace chaque puissance de 10 dans $N$

En utilisant le lemme pour chaque $k$ :

\[ N = \sum_{k=0}^{n} d_k \times 10^k = \sum_{k=0}^{n} d_k \times (3\,m_k + 1) = 3\underbrace{\left(\sum_{k=0}^{n} d_k\,m_k\right)}_{\text{entier}} + \sum_{k=0}^{n} d_k. \]

Le premier terme est un multiple de $3$. Le second terme est exactement $S$. Donc :

\[ N = (\text{multiple de } 3) + S. \]

Étape 3 — On applique la propriété clé n°1

\[ N \text{ est un multiple de } 3 \iff S \text{ est un multiple de } 3. \]

La règle est démontrée pour tout entier $N$.

Vérification sur un exemple (facultatif). Pour $N = 5\,412$ : $S = 12 = 3 \times 4$, donc $5\,412$ est bien un multiple de $3$.
Bonus. Le même raisonnement marche pour $9$, car $10 = 9 + 1$ : toute puissance de $10$ s'écrit aussi comme un multiple de $9$ plus $1$.
5

Divisibilité par 5

On regarde seulement le chiffre des unités.

Règle

Un nombre est divisible par $5$ si et seulement si son chiffre des unités est $0$ ou $5$.

Illustration

Exemples

  • ✓ $4\,735$ : le chiffre des unités est $5$, donc $4\,735$ est dans la table de $5$.
  • ✓ $2\,340$ : le chiffre des unités est $0$, donc c'est un multiple de $5$.
  • ✗ $4\,738$ : le chiffre des unités est $8$, donc $4\,738$ n'est pas un multiple de $5$.

Démonstration générale

Soit $N$ un entier naturel quelconque, écrit $N = 10a + b$ avec $b \in \{0,1,\dots,9\}$ le chiffre des unités.

Étape 1 — La différence $N - b$ est un multiple de $5$

\[ N - b = 10a = 5 \times 2a. \]

Donc $N - b$ est un multiple de $5$, quel que soit $a$.

Étape 2 — On applique la propriété clé n°1

\[ N \text{ est un multiple de } 5 \iff b \text{ est un multiple de } 5. \]

Étape 3 — On conclut

Parmi les chiffres $0, 1, \dots, 9$, seuls $0$ et $5$ sont des multiples de $5$. Donc :

\[ N \text{ est divisible par } 5 \iff b \in \{0,5\}. \]

La règle est démontrée pour tout entier $N$.

Vérification sur un exemple (facultatif). Pour $N = 4\,735$ : $b = 5$, donc $4\,735$ est bien un multiple de $5$.
7

Divisibilité par 7

On retire le double du dernier chiffre.

Règle

Soit $N = 10a + b$ où $b$ est le chiffre des unités. Alors :

\[ N \text{ est un multiple de } 7 \iff a - 2b \text{ est un multiple de } 7. \]

Illustration

Exemples

  • ✓ $4\,081$ : $a = 408$, $b = 1$, donc $a - 2b = 406 = 7 \times 58$.
  • ✗ $1\,234$ : $a = 123$, $b = 4$, donc $a - 2b = 115$, qui n'est pas dans la table de $7$.

Démonstration générale

Soit $N$ un entier naturel quelconque, écrit $N = 10a + b$ avec $b \in \{0,\dots,9\}$.

Étape 1 — Une identité vraie pour tout $N$

Calculons $10(a - 2b)$ et faisons apparaître $N$ :

\[ 10(a - 2b) = 10a - 20b = \underbrace{(10a + b)}_{=\,N} - 21b = N - 21b. \]

Donc, pour tout entier $N$ :

\[ N = 10(a - 2b) + 21b. \]

Étape 2 — Le nombre $21b$ est un multiple de $7$

En effet, $21b = 7 \times 3b$, quel que soit $b$.

Étape 3 — On applique la propriété clé n°1

$N$ et $10(a - 2b)$ diffèrent d'un multiple de $7$, donc :

\[ N \text{ est un multiple de } 7 \iff 10(a - 2b) \text{ est un multiple de } 7. \]

Étape 4 — On enlève le facteur $10$

On utilise la propriété clé n°2. Le nombre $7$ est premier. De plus, $7$ ne divise pas $10$. Donc :

\[ 7 \mid 10(a - 2b) \iff 7 \mid (a - 2b). \]

Étape 5 — Conclusion

\[ N \text{ est un multiple de } 7 \iff a - 2b \text{ est un multiple de } 7. \]

La règle est démontrée pour tout entier $N$.

Vérification sur un exemple (facultatif). Pour $N = 4\,081$ : $a - 2b = 406 = 7 \times 58$, donc $4\,081$ est bien un multiple de $7$.
11

Divisibilité par 11

On fait la somme alternée des chiffres.

Règle

Un nombre est divisible par $11$ si et seulement si la somme alternée de ses chiffres (en partant de la droite) est divisible par $11$.

Illustration

Exemples

  • ✓ $91\,839$ : $9 - 3 + 8 - 1 + 9 = 22 = 2 \times 11$.
  • ✗ $4\,738$ : $8 - 3 + 7 - 4 = 8$, qui n'est pas dans la table de $11$.
  • ✓ $2\,728$ : $8 - 2 + 7 - 2 = 11$.

Démonstration générale

Soit $N$ un entier naturel quelconque, écrit :

\[ N = d_n \times 10^n + \cdots + d_1 \times 10 + d_0. \]

On appelle somme alternée le nombre $A = d_0 - d_1 + d_2 - d_3 + \cdots$

Étape 1 — Un lemme sur les puissances de 10

Lemme. Pour tout entier $k \geqslant 0$, il existe un entier $m_k$ tel que :

\[ 10^k = 11\,m_k + (-1)^k. \]

Preuve (par récurrence).

  • Cas de base : $10^0 = 1 = 11 \times 0 + (-1)^0$. Donc $m_0 = 0$.
  • Hérédité : si $10^k = 11\,m_k + (-1)^k$, alors : \[ 10^{k+1} = 10 \times 11\,m_k + 10 \times (-1)^k = 11(10\,m_k) + 11 \times (-1)^k + (-1)^{k+1}. \] Donc $10^{k+1} = 11\bigl(10\,m_k + (-1)^k\bigr) + (-1)^{k+1}$. On pose $m_{k+1} = 10\,m_k + (-1)^k$.
  • Conclusion : la propriété est vraie pour tout $k$. ∎

Étape 2 — On remplace chaque puissance de 10 dans $N$

\[ N = \sum_{k=0}^{n} d_k \times 10^k = 11\underbrace{\left(\sum_{k=0}^{n} d_k\,m_k\right)}_{\text{entier}} + \sum_{k=0}^{n} d_k\,(-1)^k. \]

Le second terme est exactement $A$. Donc :

\[ N = (\text{multiple de } 11) + A. \]

Étape 3 — On applique la propriété clé n°1

\[ N \text{ est un multiple de } 11 \iff A \text{ est un multiple de } 11. \]

La règle est démontrée pour tout entier $N$.

Vérification sur un exemple (facultatif). Pour $N = 91\,839$ : $A = 22 = 11 \times 2$, donc $91\,839$ est bien un multiple de $11$.
13

Divisibilité par 13

On ajoute le quadruple du dernier chiffre.

Règle

Soit $N = 10a + b$ où $b$ est le chiffre des unités. Alors :

\[ N \text{ est un multiple de } 13 \iff a + 4b \text{ est un multiple de } 13. \]

Illustration

Exemples

  • ✓ $2\,899$ : $a = 289$, $b = 9$, donc $a + 4b = 325 = 13 \times 25$.
  • ✗ $4\,738$ : $a = 473$, $b = 8$, donc $a + 4b = 505$, qui n'est pas dans la table de $13$.

Démonstration générale

Soit $N$ un entier naturel quelconque, écrit $N = 10a + b$ avec $b \in \{0,\dots,9\}$.

Étape 1 — Une identité vraie pour tout $N$

\[ 10(a + 4b) = 10a + 40b = \underbrace{(10a + b)}_{=\,N} + 39b = N + 39b. \]

Donc, pour tout entier $N$ :

\[ N = 10(a + 4b) - 39b. \]

Étape 2 — Le nombre $39b$ est un multiple de $13$

En effet, $39b = 13 \times 3b$.

Étape 3 — On applique la propriété clé n°1

\[ N \text{ est un multiple de } 13 \iff 10(a + 4b) \text{ est un multiple de } 13. \]

Étape 4 — On enlève le facteur $10$

$13$ est premier et ne divise pas $10$. D'après la propriété clé n°2 :

\[ 13 \mid 10(a + 4b) \iff 13 \mid (a + 4b). \]

Étape 5 — Conclusion

\[ N \text{ est un multiple de } 13 \iff a + 4b \text{ est un multiple de } 13. \]

La règle est démontrée pour tout entier $N$.

Vérification sur un exemple (facultatif). Pour $N = 2\,899$ : $a + 4b = 325 = 13 \times 25$, donc $2\,899$ est bien un multiple de $13$.
