⚠ Web Crypto indisponible
Cette page doit être ouverte via https:// ou http://localhost. En local sur file://, la Web Crypto API est désactivée.

🔑 Configuration initiale (à faire une seule fois)

La clé privée n'est pas configurée. Génère une paire de clés (RSA-OAEP 2048 bits), puis colle la clé publique dans eleve.html et la clé privée dans prof.html.

1️⃣ Clé publique → à coller dans eleve.html

2️⃣ Clé privée → à coller dans prof.html
