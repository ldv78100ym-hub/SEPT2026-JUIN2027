Nombres complexes

Cours pédagogique – Terminale générale, option mathématiques expertes

1 Pourquoi inventer un nouveau nombre ?

« Chers élèves, pour trouver mon trésor, il vous faudra d'abord accepter d'inventer un nombre qui n'existe pas… vraiment. »

▸ Le problème : Dans $\mathbb{R}$, l'équation $x^2 = -4$ n'a pas de solution.

▸ L'idée géniale (XVIe siècle) : Les mathématiciens italiens ont inventé un nombre noté $i$ avec la règle :

\[ i^2 = -1 \]

Grâce à cette seule règle, on peut écrire :

\[ \sqrt{-4} = \sqrt{4 \times (-1)} = \sqrt{4} \times \sqrt{-1} = 2i \]
Exemple
$\sqrt{-9} = 3i$
Exemple
$\sqrt{-16} = 4i$
Exemple
$\sqrt{-25} = 5i$

📌 À retenir : $i$ est un imaginaire pur. Il n'appartient pas à $\mathbb{R}$, mais il est parfaitement défini par $i^2 = -1$.

2 La forme algébrique

Définition

Un nombre complexe s'écrit sous la forme algébrique :

\[ z = a + bi \quad \text{où } a \in \mathbb{R},\; b \in \mathbb{R},\; i^2 = -1 \]
  • $a$ est la partie réelle : $\operatorname{Re}(z) = a$
  • $b$ est la partie imaginaire : $\operatorname{Im}(z) = b$

Imaginaire pur

Si $a = 0$, alors $z = bi$.

Exemple : $z = 3i$

Nombre réel

Si $b = 0$, alors $z = a$.

Exemple : $z = 5$

Notation : L'ensemble de tous les nombres complexes est noté $\mathbb{C}$.

Exemples de la forme algébrique

  • $z_1 = 1 + i \quad \Rightarrow \quad \operatorname{Re}(z_1)=1,\; \operatorname{Im}(z_1)=1$
  • $z_2 = 2 + 4i \quad \Rightarrow \quad \operatorname{Re}(z_2)=2,\; \operatorname{Im}(z_2)=4$
  • $z_3 = 3 + 3i \quad \Rightarrow \quad \operatorname{Re}(z_3)=3,\; \operatorname{Im}(z_3)=3$
3 Opérations sur les complexes
3.1 Addition

On additionne deux nombres complexes en additionnant parties réelles entre elles et parties imaginaires entre elles :

\[ (a + bi) + (c + di) = (a + c) + (b + d)i \]
Exemple
$(3 + 2i) + (1 - 5i) = 4 - 3i$
Exemple
$(-2 + i) + (4 + 4i) = 2 + 5i$
3.2 Multiplication

On multiplie comme avec des expressions littérales, en remplaçant $i^2$ par $-1$ :

\[ (a + bi)(c + di) = (ac - bd) + (ad + bc)i \]

⚡ Démonstration : on développe $ac + adi + bci + bd\,i^2$, puis on remplace $i^2$ par $-1$.

Exemple traité
$(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 2 + i + 3 = 5 + i$
Donc $P = 5 + i$ avec $a=5,\; b=1$.
4 Module d'un nombre complexe

Le module d'un nombre complexe $z = a + bi$ est la distance entre l'origine du repère et le point d'affixe $z$.

\[ |z| = \sqrt{a^2 + b^2} \]

📐 D'où vient cette formule ?

Dans le plan complexe, le point $M(a;b)$ forme un triangle rectangle avec l'origine. Par le théorème de Pythagore :

\[ OM^2 = a^2 + b^2 \quad \Rightarrow \quad OM = \sqrt{a^2 + b^2} \]
Exemple
$z = 3 + 4i \quad \Rightarrow \quad |z| = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$
Exemple
$z = 1 - i \quad \Rightarrow \quad |z| = \sqrt{1^2 + (-1)^2} = \sqrt{2}$
5 Représentation géométrique

À tout nombre complexe $z = a + bi$, on associe le point $M(a;b)$ du plan. On dit que :

  • $z$ est l'affixe du point $M$ ;
  • $M$ est le point image de $z$.

Le plan muni d'un repère orthogonal $(O; \vec{u}, \vec{v})$ où l'axe horizontal est l'axe des parties réelles et l'axe vertical l'axe des parties imaginaires est appelé plan complexe (ou plan d'Argand).

Exemple : Les points correspondants aux affixes suivantes

  • $z_A = (2+i)+(1-3i) = 3 - 2i \;\Rightarrow\; A(3;-2)$
  • $z_B = (1+i)^2 = 1 + 2i + i^2 = 2i \;\Rightarrow\; B(0;2)$
  • $z_C = i(1-3i) = i - 3i^2 = 3 + i \;\Rightarrow\; C(3;1)$
  • $z_D = (-1+2i)(3-i) + 7 - 7i = \dots = 2 + 2i \;\Rightarrow\; D(2;2)$
A (3 ; -2) B (0 ; 2) C (3 ; 1) D (2 ; 2) O (0 ; 0)
