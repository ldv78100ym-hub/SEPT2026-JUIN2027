1 · Définition et sens de variation

log(b) : l'unique solution de l'équation 10x = b

📐 Définition

Soit b > 0. L'équation d'inconnue réelle x : 10x = b admet une unique solution. Cette solution s'appelle le logarithme décimal de b, notée log(b) (ou log b).

10log b = b   et   log(10x) = x

La fonction x ↦ log x est définie sur ]0 ; +∞[ et « échange » la base 10 et l'exposant.

🧠 Pourquoi existence et unicité ? (le cœur de la rigueur)

Unicité : si 10u = 10v, alors comme x ↦ 10x est strictement croissante, u ≠ v est impossible : deux exposants différents donnent deux valeurs différentes. Donc au plus une solution.

Existence : x ↦ 10x est continue et strictement croissante sur ℝ ; ses valeurs parcourent tout ]0 ; +∞[ (elle tend vers 0 quand x → −∞ et vers +∞ quand x → +∞). Tout b > 0 est donc atteint, une seule fois.

Conséquence : pour b ≤ 0, l'équation n'a aucune solution — c'est pourquoi log n'est définie que sur les réels strictement positifs.

En particulier : log 1 = 0 (car 10⁰ = 1), log 10 = 1 (car 10¹ = 10), et pour tout entier n : log(10ⁿ) = n.

🪞 log et 10x : des fonctions réciproques

Puisque log(b) est par définition la solution de 10x = b, on a 10log b = b. Réciproquement, log(10x) = x car 10x est… une puissance de 10 ! Les courbes de log et de 10x sont donc symétriques par rapport à la droite y = x, et leurs variations sont liées.

📈 Sens de variation

Propriété fondamentale

La fonction log est strictement croissante sur ]0 ; +∞[.

🧠 Démonstration (2 lignes, mais 2 lignes de qualité)

Soient 0 < a < b. Posons A = log a et B = log b. Alors 10A = a < b = 10B. Comme x ↦ 10x est strictement croissante, on a nécessairement A < B.

Donc 0 < a < b ⟹ log a < log b : c'est exactement la stricte croissance de log. (La réciproque d'une fonction strictement croissante est strictement croissante.)

Tableau de variations

x     0       +∞
log x  −∞  ↗  +∞

lim log x = −∞ quand x → 0⁺, et +∞ quand x → +∞ : log balaye tout ℝ.

Signe de log (très utile)

  • 0 < b < 1 ⟹ log b < 0
  • b = 1 ⟹ log b = 0
  • b > 1 ⟹ log b > 0

Exemples : log 0,5 ≈ −0,301 ; log 7 ≈ 0,845.

📌 À retenir

  • log b est un exposant : celui qu'il faut mettre sur 10 pour obtenir b.
  • log n'est définie que pour b > 0 : log 0 et log(−5) n'existent pas.
  • log(10x) = x pour tout réel x ; 10log b = b pour tout b > 0.
  • La croissance de log permet de comparer sans calculer : 57 < 63 ⟹ log 57 < log 63.
