2 · Propriétés algébriques et transformations

Le produit devient somme, le quotient devient différence, la puissance devient facteur

📐 Les quatre propriétés (a et b réels strictement positifs, n entier naturel)

log(a·b) = log a + log b

le produit devient une somme

log(a/b) = log a − log b

le quotient devient une différence

log(1/b) = − log b

l'inverse devient l'opposé

log(bⁿ) = n · log b

la puissance devient un facteur

Remarque : log(a/b) = log(a · 1/b) = log a + log(1/b) = log a − log b — la 2ᵉ et la 3ᵉ propriété sont sœurs.

🧠 Démonstrations à partir de la seule définition (élégant et rigoureux)

Produit : notons A = log a, B = log b. Alors 10A+B = 10A · 10B = a·b (règle sur les puissances). Donc A+B est une solution de 10x = a·b ; par unicité, A + B = log(a·b).

Inverse : 10−B = 1/10B = 1/b, donc −B est solution de 10x = 1/b : −log b = log(1/b).

Puissance : 10n·log b = (10log b)ⁿ = bⁿ, donc n·log b = log(bⁿ) par unicité.

Toutes ces preuves tiennent en une ligne : composer 10▪ avec la définition et invoquer l'unicité de la solution.

⚠️ Pièges classiques (à ne jamais commettre)

  • log(a + b) ≠ log a + log b. Contre-exemple : log(2 + 8) = log 10 = 1, mais log 2 + log 8 = log 16 ≈ 1,204.
  • Les propriétés exigent des nombres strictement positifs : log(−2 · 3) n'existe pas.
  • log(bⁿ) = n·log b vaut pour n entier naturel ; avec b > 0, on peut l'étendre à tout entier relatif (log(2⁻³) = −3·log 2), car 10⁻ᵐ = 1/10ᵐ.

🔧 Transformer des expressions

Réflexes numériques

  • log 4 + log 25 = log 100 = 2
  • log 0,003 = log(3/1000) = log 3 − 3 ≈ −2,523
  • log 72 = log(8·9) = 3·log 2 + 2·log 3 ≈ 1,857
  • log 5 = log(10/2) = 1 − log 2 ≈ 0,699
  • log(1/2) = −log 2 ≈ −0,301

Réflexes littéraux (a, b, x > 0)

  • log(a²b) = 2·log a + log b
  • log(x³/y²) = 3·log x − 2·log y
  • log(10x) = 1 + log x
  • log(0,1·a) = log a − 1
  • n·log 2 = log(2ⁿ)

📝 Exercices de synthèse

Exercice 1

Sachant log 2 ≈ 0,301 et log 3 ≈ 0,477, calculer sans machine log 6, log 54 et log 0,4.

✍️ Voir la solution détaillée

log 6 = log(2·3) = log 2 + log 3 ≈ 0,778.

log 54 = log(2·27) = log 2 + 3·log 3 ≈ 0,301 + 1,431 = 1,732.

log 0,4 = log(4/10) = 2·log 2 − 1 ≈ 0,602 − 1 = −0,398. (Un nombre < 1 : log négatif, tout va bien.)

Exercice 2

Une eau de pluie acide a un pH de 4,5, celui d'une eau neutre est 7. Par combien la concentration en ions H⁺ est-elle multipliée ?

✍️ Voir la solution détaillée

pH = −log[H⁺], donc [H⁺] = 10−pH. Eau neutre : 10⁻⁷ ; pluie : 10−4,5.

Rapport : 10−4,5/10−7 = 107−4,5 = 102,5 ≈ 316.

L'eau de pluie est environ 316 fois plus concentrée en ions H⁺. Réflexe : un écart de pH de 2,5 ⟹ un facteur 102,5.
