3 · Équations et inéquations

log(x) = a, 10x = b, log(x) ⋚ a, 10x ⋚ b — d'inconnue x réelle

✅ Équations

🧭 Équation du type log(x) = a

log(x) = a ⇔ x = 10a

Pour tout a réel, la solution existe, est unique, et est bien > 0 (domaine respecté automatiquement).

Exemple : log x = 2,5 ⟹ x = 102,5 = 100·√10 ≈ 316,2.

🧭 Équation du type 10x = b

10x = b ⇔ x = log b  (si b > 0)

Si b ≤ 0 : aucune solution, car 10x > 0 pour tout x.

Exemple : 10x = 7 ⟹ x = log 7 ≈ 0,845.

📝 Exercices — équations

Exercice 1

Résoudre dans ℝ : log(3x + 1) = 2.

✍️ Voir la solution détaillée

Étape 1 — domaine : il faut 3x + 1 > 0, soit x > −1/3.

Étape 2 — on applique 10▪ : log(3x + 1) = 2 ⇔ 3x + 1 = 10² = 100.

Étape 3 — on résout : 3x = 99, donc x = 33.

Vérification : 3·33 + 1 = 100 > 0 ✓ et log(100) = 2 ✓. Solution : S = {33}.

Exercice 2

Résoudre dans ℝ : 102x−1 = 50.

✍️ Voir la solution détaillée

50 > 0 : une solution existe. On applique log aux deux membres : 2x − 1 = log 50 = log(100/2) = 2 − log 2 ≈ 1,699.

D'où 2x = 2,699, puis x = (1 + log 50)/2 ≈ 1,349. Vérification : 102×1,349−1 ≈ 101,699 ≈ 50 ✓.

Exercice 3 (plus costaud)

Résoudre dans ℝ : log x + log(x − 9) = 2.

✍️ Voir la solution détaillée

Étape 1 — domaine : x > 0 et x − 9 > 0, donc x > 9.

Étape 2 — produit : log x + log(x − 9) = log(x(x − 9)) = 2 ⇔ x(x − 9) = 100.

Étape 3 — second degré : x² − 9x − 100 = 0. Discriminant : 81 + 400 = 481, √481 ≈ 21,93. Racines : (9 − 21,93)/2 ≈ −6,47 (refusée : < 9) et (9 + 21,93)/2 ≈ 15,47 (acceptée).

Conclusion : S ≈ {15,47}. Toujours contrôler les solutions par rapport au domaine !

⚖️ Inéquations

🧭 La règle d'or

log et 10▪ sont strictement croissantes : on peut les appliquer aux deux membres d'une inéquation sans changer le sens (à condition d'être dans le domaine !).

log(x) < a ⇔ 0 < x < 10a   ·   10x ≤ b ⇔ x ≤ log b (b > 0)

🎯 Explorateur d'inéquations

⚠️ Les deux pièges mortels

  • Le domaine d'abord ! Dans log(x) < a, la réponse est un intervalle ouvert en 0 : x reste > 0. Écrire x < 10a seul est incomplet.
  • Le cas b ≤ 0 dans 10x ⋚ b : 10x est toujours > 0. Donc 10x ≤ b (b ≤ 0) : aucune solution ; 10x > b (b ≤ 0) : vrai pour tout x, S = ℝ.

📝 Exercices — inéquations

Exercice 4

Résoudre dans ℝ : log(x) ≥ −1,5.

✍️ Voir la solution détaillée

Domaine : x > 0. On applique 10▪ (strictement croissante) : log x ≥ −1,5 ⇔ x ≥ 10−1,5 = 1/31,62 ≈ 0,0316.

S = [0,0316 ; +∞[ (environ). Remarquez le crochet fermé : l'inégalité est large.

Exercice 5

Résoudre dans ℝ : 103x ≤ 64.

✍️ Voir la solution détaillée

64 > 0 : on peut appliquer log (strictement croissante, sens conservé) :

103x ≤ 64 ⇔ 3x ≤ log 64 = log(2⁶) = 6·log 2 ≈ 1,806 ⇔ x ≤ 0,602.

S = ]−∞ ; 0,602] (environ).

Exercice 6

Résoudre dans ℝ : log(2x) < 0,8.

✍️ Voir la solution détaillée

Domaine : 2x > 0 donc x > 0. On applique 10▪ : log(2x) < 0,8 ⇔ 2x < 100,8 ≈ 6,310 ⇔ x < 3,155.

Avec le domaine x > 0 : S = ]0 ; 3,155[ (environ). Les deux bornes sont ouvertes !
