🎓 Quiz final

📚 Formulaire

Propriétés

Définitionlog(b) = l'unique solution de 10x = b (b > 0)
Réciproques10log b = b (b > 0) ; log(10x) = x (x réel)
Valeurs cléslog 1 = 0 ; log 10 = 1 ; log(10ⁿ) = n (n entier)
Produitlog(a·b) = log a + log b (a, b > 0)
Quotientlog(a/b) = log a − log b (a, b > 0)
Inverselog(1/b) = − log b (b > 0)
Puissancelog(bⁿ) = n·log b (b > 0, n ∈ ℕ)
Variationslog strictement croissante sur ]0 ; +∞[ ; négative sur ]0 ; 1[, nulle en 1, positive après

Méthodes de résolution

log(x) = ax = 10a (unique solution, automatiquement > 0)
10x = bb > 0 : x = log b ; b ≤ 0 : pas de solution
log(x) ⋚ a0 < x ⋚ 10a (ne pas oublier le domaine !)
10x ⋚ bb > 0 : x ⋚ log b ; b ≤ 0 : ∅ ou ℝ selon le sens
qⁿ > An > log A / log q, puis plus petit entier (n ∈ ℕ)
Nombre de chiffres de Nfloor(log N) + 1
Facteur entre 10a et 10b10b−a

⚠️ Les 5 pièges à surveiller le jour J

  1. Écrire log(0) ou log(négatif) : n'existe pas — vérifiez le domaine en premier.
  2. Croire que log(a + b) = log a + log b : c'est le produit qui devient somme.
  3. Oublier la borne x > 0 dans la solution de log(x) ⋚ a.
  4. Négliger le cas b ≤ 0 dans 10x = b ou 10x ⋚ b.
  5. Donner une réponse décimale à un problème d'entier (2ⁿ > 10⁶ ⟹ n ≥ 20, pas « 19,93 »).

🚀 Pour aller plus loin

Vous entendrez parler du logarithme népérien ln (base e ≈ 2,718) dans vos études supérieures : il vérifie les mêmes propriétés, et on passe de l'un à l'autre par log(x) = ln(x)/ln(10). Tout ce que vous venez d'apprendre se transposera à l'identique !
