🔧 Détails techniques

Chiffrement : hybride RSA-OAEP (2048 bits, SHA-256) + AES-GCM (256 bits). Une clé AES aléatoire chiffre le carnet, puis cette clé AES est chiffrée par la clé publique RSA. Seule la clé privée RSA peut la récupérer.

Format du fichier : {format:"logdec-carnet-v1", algorithm:"RSA-OAEP-2048 + AES-GCM-256", encrypted_key_b64:"…", iv_b64:"…", ciphertext_b64:"…"}

Architecture : la clé publique est écrite en dur dans 00-decouverte.html, la clé privée en dur dans ce fichier. Aucun stockage navigateur n'est utilisé pour les clés.

Analyse pédagogique : l’analyse est heuristique (éléments attendus par question, mots-clés, qualités rédactionnelles). Elle aide à préparer la remédiation et le déroulé du cours, sans remplacer la lecture des réponses par l’enseignant.

Rotation : pour changer de clé, recliquez sur le générateur, puis recollez les deux nouvelles constantes dans les fichiers respectifs. Les anciens carnets deviendront illisibles avec la nouvelle clé.
