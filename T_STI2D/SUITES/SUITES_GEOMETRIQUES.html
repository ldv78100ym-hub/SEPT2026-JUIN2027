📌 Définition d'une suite géométrique

Une suite (un) est dite géométrique s'il existe un nombre réel q (appelé raison) tel que, pour tout entier n :

\[ u_{n+1} = q \times u_n \]

Autrement dit, chaque terme est obtenu en multipliant le précédent par un nombre constant q.

📘 Exemple interactif : avec \(u_0 = \) 2 et \(q = \) 1.5, les premiers termes sont : 2, 3, 4.5, 6.75, 10.125, 15.1875 (car chaque terme est multiplié par \(q\)).
⚠️ Attention : si \(q = 0\), la suite devient nulle à partir du premier terme. Si \(q = 1\), la suite est constante. Si \(q < 0\), les termes alternent de signe.

🔢 Formule explicite

Si on connaît le premier terme \(u_0\) et la raison \(q\), on peut calculer directement le terme de rang \(n\) :

\[ u_n = u_0 \times q^n \]

Cette formule est fondamentale : elle évite de calculer tous les termes intermédiaires.

🧮 Somme des termes consécutifs

On note \(S_n\) la somme des premiers termes \(u_0 + u_1 + \cdots + u_{n-1}\). Pour une suite géométrique de raison \(q \neq 1\) :

\[ S_n = u_0 \times \frac{1 - q^n}{1 - q} \]

Si \(q = 1\), la suite est constante et \(S_n = n \times u_0\).

💡 On utilise souvent la somme des termes de \(u_0\) à \(u_{n-1}\) (soit \(n\) termes). Pour la somme de \(u_p\) à \(u_m\) (termes consécutifs), on peut utiliser : \[ u_p + u_{p+1} + \cdots + u_m = u_p \times \frac{1 - q^{m-p+1}}{1 - q} \]

Vérification : \(2 + 3 + 4.5 + 6.75 + 10.125 + 15.1875 = 41.0625\).

🐍 Python – Boucle for

La boucle for est parfaite pour parcourir les termes d'une suite géométrique lorsqu'on connaît à l'avance le nombre de termes.

🐍 PYTHON Fonction termes_geo(u0, q, n) – retourne la liste des \(n\) premiers termes de la suite \((u_0, u_1, \dots, u_{n-1})\).
def termes_geo(u0, q, n): """Retourne les n premiers termes d'une suite géométrique""" termes = [] for i in range(n): termes.append(u0 * (q ** i)) return termes
💡 À retenir : range(n) génère les entiers de \(0\) à \(n-1\). On utilise q ** i pour calculer \(q^i\).
🧪 Exécuter & comprendre COMPRENDRE

La fonction ci-dessous calcule la somme des \(n\) premiers termes d'une suite géométrique. Comprenez chaque ligne, puis cliquez sur Exécuter pour voir le résultat pour \(u_0=3\), \(q=2\), \(n=5\).

def somme_geo(u0, q, n): """Somme des n premiers termes u0 + ... + u_{n-1}""" if q == 1: return n * u0 return u0 * (1 - q ** n) / (1 - q)
Cliquez sur Exécuter pour voir le résultat.
💬 Explication : la fonction somme_geo utilise la formule de la somme. Si \(q=1\), elle retourne \(n \times u_0\). Sinon, elle applique la formule avec la division. Remarquez qu'il n'y a pas de print() : le résultat est retourné (return).

🐍 Python – Boucle while

La boucle while est utile quand on ne connaît pas à l'avance le nombre d'itérations, par exemple pour trouver le rang où un terme dépasse un seuil.

🐍 PYTHON Fonction rang_seuil(u0, q, seuil) – retourne le plus petit entier \(n\) tel que \(u_n \geqslant \text{seuil}\).
def rang_seuil(u0, q, seuil): """Plus petit n tel que u_n >= seuil (u0 > 0, q > 1)""" n = 0 terme = u0 while terme < seuil: n += 1 terme *= q return n

🐍 Python – Conditions if / else

Les conditions permettent de traiter différents cas. Pour les suites géométriques, le cas \(q = 1\) est particulier pour la somme.

🐍 PYTHON Fonction somme_geo_condition(u0, q, n) – avec gestion du cas \(q = 1\).
def somme_geo_condition(u0, q, n): """Somme des n premiers termes, avec gestion de q=1""" if q == 1: return n * u0 elif q > 1: return u0 * (q ** n - 1) / (q - 1) else: return u0 * (1 - q ** n) / (1 - q)

🐍 Python – Fonctions pour les suites géométriques

Regroupons tout dans un module cohérent. Les fonctions suivantes utilisent boucles, conditions et retour de valeurs (jamais de print()).

# --- Module suites_geo --- def terme(u0, q, n): return u0 * (q ** n) def somme(u0, q, n): if q == 1: return n * u0 return u0 * (1 - q ** n) / (1 - q) def liste_termes(u0, q, n): return [u0 * (q ** i) for i in range(n)] def liste_sommes(u0, q, n): S = 0 res = [] for i in range(n): S += u0 * (q ** i) res.append(S) return res
💡 Remarque : toutes ces fonctions retournent des valeurs. Elles n'affichent rien à l'écran. C'est à l'appelant (le code qui les utilise) de décider quoi faire du résultat.

📖 Solutions détaillées

Correction :

def trouver_raison(un, un_plus_1): if un == 0: return "indéfini" return un_plus_1 / un

La raison d'une suite géométrique est le quotient de deux termes consécutifs : \(q = \dfrac{u_{n+1}}{u_n}\).

La fonction mystere calcule la somme des termes d'une suite géométrique en partant de \(u_0\), et retourne le premier indice i pour lequel la somme partielle dépasse 50. Si aucune somme ne dépasse 50 sur les \(n\) premiers termes, elle retourne -1.

Pour \(u_0=2\), \(q=3\), \(n=4\) :
\(S_0 = 2\) (≤ 50)
\(S_1 = 2+6 = 8\) (≤ 50)
\(S_2 = 8+18 = 26\) (≤ 50)
\(S_3 = 26+54 = 80\) (> 50) → retourne 3.

Une modification possible :

def termes_geo(u0, q, p, m): """Retourne les termes de l'indice p à l'indice m inclus""" return [u0 * (q ** i) for i in range(p, m + 1)]

On utilise range(p, m+1) pour inclure l'indice \(m\). Exemple : termes_geo(2, 3, 1, 3) retourne \([6, 18, 54]\).
