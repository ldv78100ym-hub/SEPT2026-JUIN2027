🧩 Exercice 1 – Déterminer une expression selon un contexte

📈 Placement bancaire MATHS PYTHON

🧮 Partie mathématique

Un capital de 1500 € est placé sur un livret d'épargne à 3 % d'intérêts annuels (intérêts composés). On note $u_n$ le capital disponible après $n$ années (avec $u_0 = 1500$).

  1. Justifier que la suite $(u_n)$ est géométrique. Donner sa raison $q$.
  2. Exprimer $u_n$ en fonction de $n$.
  3. Calculer le capital après 5 ans (arrondir au centime près).
  4. Au bout de combien d'années le capital aura-t-il doublé ? (Résoudre $u_n \geqslant 3000$ à l'aide d'un calcul de logarithme ou par tâtonnement).

🐍 Partie Python – Compléter

La fonction capital(n) doit retourner le capital après $n$ années. Complétez la ligne manquante pour qu'elle calcule $u_n$.

def capital(n): """Retourne le capital après n années""" u0 = 1500 q = 1.03 return ___
Complétez et vérifiez.

Correction mathématique :

  1. Chaque année, le capital est multiplié par $1,03$ car les intérêts s'ajoutent au capital. Ainsi, pour tout $n\in\mathbb{N}$, $u_{n+1}=1,03\,u_n$. La suite $(u_n)$ est donc géométrique de raison $q=1,03$.
  2. Par définition d'une suite géométrique, on a directement \[ u_n = u_0 \times q^n = 1500 \times 1,03^n. \]
  3. Pour $n=5$ : \[ u_5 = 1500 \times 1,03^5. \] Calculons $1,03^5$ : $1,03^2=1,0609$, $1,03^3=1,092727$, $1,03^4=1,12550881$, $1,03^5=1,1592740743$. Donc \[ u_5 = 1500 \times 1,1592740743 \approx 1738,91111145 \approx 1738,91\ \text{€}. \]
  4. On cherche le plus petit entier $n$ tel que $u_n \geqslant 3000$. \[ 1500 \times 1,03^n \geqslant 3000 \iff 1,03^n \geqslant 2 \iff \ln(1,03^n) \geqslant \ln 2 \iff n\,\ln(1,03) \geqslant \ln 2 \iff n \geqslant \frac{\ln 2}{\ln 1,03}. \] Avec $\ln 2 \approx 0,693147$ et $\ln 1,03 \approx 0,029559$, \[ \frac{\ln 2}{\ln 1,03} \approx 23,45. \] Le plus petit entier $n$ vérifiant cette inégalité est donc $n=24$. Le capital aura doublé au bout de 24 ans.

Correction Python : return u0 * (q ** n)

Finalement, la suite est géométrique de raison $1,03$, son terme général est $u_n=1500\times 1,03^n$, le capital après 5 ans est d'environ 1738,91 € et il dépasse 3000 € pour la première fois à $n=24$.

➕ Exercice 4 – Somme des n premiers termes (u₀ à uₙ₋₁)

➕ Somme classique MATHS PYTHON

🧮 Partie mathématique

On considère la suite géométrique définie par $u_0 = 3$ et $q = 2$.

  1. Rappeler la formule donnant la somme $S_n = u_0 + u_1 + \cdots + u_{n-1}$.
  2. Calculer $S_5$ (somme des 5 premiers termes).
  3. Vérifier le résultat en additionnant les termes un par un.

🐍 Partie Python – Comprendre

La fonction ci-dessous calcule cette somme. Expliquez en français pourquoi on distingue le cas q == 1 et ce que fait la formule dans le return.

def somme_premiers(u0, q, n): if q == 1: return n * u0 return u0 * (1 - q ** n) / (1 - q)
Écrivez votre explication.

Correction mathématique :

  1. Pour une suite géométrique de raison $q\neq 1$, la somme des $n$ premiers termes (de $u_0$ à $u_{n-1}$) est : \[ S_n = u_0 \times \frac{1 - q^n}{1 - q}. \] Si $q=1$, la suite est constante égale à $u_0$ et $S_n = n u_0$.
  2. Ici $u_0=3$, $q=2$, $n=5$ : \[ S_5 = 3 \times \frac{1 - 2^5}{1 - 2} = 3 \times \frac{1 - 32}{-1} = 3 \times \frac{-31}{-1} = 3 \times 31 = 93. \]
  3. Vérification terme à terme : \[ u_0=3,\quad u_1=6,\quad u_2=12,\quad u_3=24,\quad u_4=48. \] La somme vaut $3+6+12+24+48 = 93$. Le résultat est cohérent.

Compréhension Python :

  • Le cas q == 1 est traité séparément car la formule u0 * (1 - q**n) / (1 - q) contient une division par zéro lorsque $q=1$.
  • Dans ce cas, la suite est constante : $u_n = u_0$ pour tout $n$, donc la somme des $n$ premiers termes vaut $n \times u_0$.
  • Pour $q\neq 1$, la formule classique s'applique directement.
Finalement, la somme des 5 premiers termes de la suite géométrique de premier terme 3 et de raison 2 vaut $S_5=93$, ce qui est confirmé par l'addition directe des termes.

📐 Formule d'une suite géométrique

Une suite géométrique de premier terme $u_0$ et de raison $q$ est définie par :

$u_n = u_0 \times q^n$

Cette formule est valable pour tout entier $n \geqslant 0$. Elle permet de calculer n'importe quel terme sans avoir à itérer.

⚡ Règles de calcul sur les puissances

  • $a^n \times a^m = a^{n+m}$
  • $(a^n)^m = a^{n\times m}$
  • $\dfrac{a^n}{a^m} = a^{n-m}$
  • $a^0 = 1$ (pour $a \neq 0$)
  • $a^{-n} = \dfrac{1}{a^n}$

Par exemple, $1,5^4 = (1,5^2)^2 = 2,25^2 = 5,0625$.

🔢 Puissances et racines

Pour résoudre $q^3 = 8$, on utilise la racine cubique : $q = \sqrt[3]{8} = 2$.

En Python, l'opérateur ** permet d'élever à une puissance : 8 ** (1/3) donne la racine cubique.

De manière générale, $x^{1/n} = \sqrt[n]{x}$.

➕ Somme des premiers termes d'une suite géométrique

Pour $q \neq 1$, la somme des $n$ premiers termes (de $u_0$ à $u_{n-1}$) est :

$S_n = u_0 \times \dfrac{1 - q^n}{1 - q}$

Si $q = 1$, la suite est constante et $S_n = n \times u_0$.

➕ Somme décalée (de $u_1$ à $u_n$)

La somme de $u_1$ à $u_n$ est une somme géométrique de premier terme $u_1 = u_0 q$ et de raison $q$ :

$T_n = u_0 q \times \dfrac{1 - q^n}{1 - q}$

Elle comporte exactement $n$ termes.

➕ Somme d'une plage de termes

Pour une suite géométrique, la somme de $u_p$ à $u_m$ (avec $p \leqslant m$) est :

$S = u_p \times \dfrac{1 - q^{m-p+1}}{1 - q}$

Le nombre de termes est $m-p+1$.

📈 Logarithme népérien – propriétés

Pour tout $a>0$ et $b>0$, et pour tout $n \in \mathbb{R}$ :

  • $\ln(a \times b) = \ln a + \ln b$
  • $\ln\left(\dfrac{a}{b}\right) = \ln a - \ln b$
  • $\ln(a^n) = n \ln a$

Ces propriétés permettent de transformer des produits en sommes, des quotients en différences, et des puissances en multiplications, ce qui est très utile pour résoudre des équations ou inéquations exponentielles.

Exemple : pour résoudre $1,03^n \geqslant 2$, on applique $\ln$ : $n \ln(1,03) \geqslant \ln 2$.

🌀 Point fixe d'une suite arithmético-géométrique

Une suite arithmético-géométrique est définie par $u_{n+1} = a u_n + b$.

Le point fixe $L$ est la solution de l'équation $L = a L + b$.

Si $a \neq 1$, on a $L = \dfrac{b}{1-a}$.

Ce point fixe permet de construire une suite auxiliaire géométrique.

🌀 Suite auxiliaire

Pour une SAG $u_{n+1} = a u_n + b$, on pose $v_n = u_n - L$, où $L$ est le point fixe.

Alors $v_{n+1} = a v_n$ : $(v_n)$ est une suite géométrique de raison $a$.

On en déduit $v_n = v_0 a^n$, puis $u_n = L + (u_0 - L) a^n$.

Cette méthode est la seule autorisée en terminale STI2D (hors programme de la formule directe).
